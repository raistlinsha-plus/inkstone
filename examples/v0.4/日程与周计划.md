## 原样保留的配置

这份 JSON 独立于日历数据。以下整数超过 JavaScript 的安全整数范围，编辑日程时它应保持完整：

```json
{
  "project": "Inkstone",
  "externalDocumentId": 9007199254740993,
  "description": "日历修改不能影响相邻 JSON 的数字或正文。"
}
```

验收提示：在项目日历选择 2026-10-26 到 2026-11-01，应显示完整的 14 个事项；也可以查询“本周有哪些会议”，再核对日期范围和文档来源。此文件不包含账号、密钥或远程日历连接。
