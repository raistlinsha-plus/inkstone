# Inkstone v0.7.3 演示 · 社区阅读计划

用两份虚构笔记体验独立问答、指定资料和原文核对。下载 [阅读活动计划.md](阅读活动计划.md) 和 [阅读活动复盘.md](阅读活动复盘.md) 到同一个本地目录。

## 准备

打开 Inkstone v0.7.3。在「模型与设置」打开「问答模型」，勾选「启用资料问答」，配置自己的兼容服务并「保存设置」。这个演示使用聊天模型，附件和 Wiki 整理会把你选中的演示资料发送给该模型。无需配置向量模型或搜索服务。

## 1. 先问，再添加资料

1. 从左侧「问答」（AI 问答）打开独立工作台，直接输入「写一句邀请邻居参加周末共读的通知」。预期得到一条可复制的通知，无需先导入文档或建立索引。
2. 在输入框上方点「添加资料」→「附加临时文件」，选择 `阅读活动计划.md`。再点一次「附加临时文件」，选择 `阅读活动复盘.md`。确认两份文件都出现在输入框上方的标签中。
3. 发送下面这句话。预期回答写出计划 **4 场**、已完成 **2 场**、**满意度未知**，并引用两份附件。回答措辞和引用顺序随模型而异。

   > 只根据这两份附件回答：春芽社区阅读计划本期计划举办几场，已完成几场，满意度能确定吗？请给出原文引用。

4. 展开「本轮查阅」和「本轮资料依据」。打开一个「临时文件」来源，再点「打开附件」，核对计划或完成场数所在的原文。两项数字分别来自不同文件。当前没有满意度调查结果。

## 2. 可选 · 在文档空间浏览 Wiki 和原文

1. 回到左侧「文档」，选一个受管理的文档空间或新建演示空间。点「导入文档」→「选择文件（可多选）」，选中两份笔记，检查「导入到空间」后点「复制导入」。
2. 在同一空间打开左侧「Wiki」。进入「范围与维护」，勾选「启用当前空间的 Wiki」，将「关注主题」填为 `春芽社区阅读计划`，仅勾选这两篇资料。「维护方式」选择「发布前全部审阅」，点「保存范围与维护」。
3. 点「整理所选资料」。完成后到「最近变更」查看候选，核对摘录再点「发布改动」。回到「页面」，点已生效的主题，再展开「原文位置」并点一个行号范围，核对是否跳到对应文档。主题名和页面数量随模型而异。
4. 回到「AI 问答」，用「添加资料」下的「知识空间」选择刚才的空间，再勾选两篇已导入的笔记。移除输入框上方仍选中的临时文件，再问同一个问题，将其中的「附件」替换为「文档」。这次预期引用类型为「文档」，可点「打开文档」查看对应原件。显式选择文档会优先查阅这些原文。Wiki 页面可从自己的入口另行核对。
