# 智能文本工具项目计划

## 首版目标

第一个版本面向 macOS Apple Silicon，提供本地文本编辑、Markdown 可视化编辑、本地知识索引和用户 API 问答。

## 技术方案

桌面框架使用 Tauri 2，本地服务使用 Rust，界面使用 React 和 TypeScript。源码编辑使用 CodeMirror，可视化编辑使用 Milkdown，Markdown 解析使用 remark。

全文搜索使用 SQLite FTS5，中文分词使用 jieba-rs，向量搜索使用 sqlite-vec。检索结果使用 RRF 合并关键词和语义排名。

## 暂缓范围

PDF、DOCX、OCR、云同步和多人协作不在首版范围内。首版不会自动下载或运行大型本地模型。

## 验收标准

| 项目 | 标准 |
| --- | --- |
| 本机运行 | macOS 桌面窗口与独立应用可打开 |
| 文件保护 | 不静默覆盖其他应用的修改 |
| 搜索 | 中文关键词能返回原文片段 |
| 引用 | 能打开文档并定位相应行 |
