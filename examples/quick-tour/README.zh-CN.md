# 用一篇 Markdown 笔记试用砚台

[English](README.md) · [直接在浏览器体验](https://raistlinsha-plus.github.io/inkstone/?lang=zh-CN)

两场阅读活动选了不同场地。手头有参与人数，也有一件事要安排。打开 Inkstone 后，花三分钟走一遍下面的流程。看图表和安排任务都可以离线完成。体验真实问答需要先配置问答模型，也可以用浏览器演示里的示例回答体验引用。

1. **打开笔记，核对人数。** 在 GitHub 打开[示例笔记](zh-CN/reading-activity.md)，点文件右上方的 **Download raw file** 下载 Markdown。在 Inkstone 的「我的文档」选择一个空间，点「导入文档」，导入刚下载的文件。用「正文」打开笔记，把鼠标移到图表上，或按 Tab 聚焦到图表工具栏。切到「数据表」，查看甲、乙两场的人数。
2. **从回答回到原句。** 点「问这篇文档」，输入“哪场阅读活动的参与人数更多？请引用两场的人数。”点开引用，对照原文第 7–10 行的表格。甲方案有 120 人，乙方案有 80 人。接着问“哪场活动的满意度更高？”第 12 行说明了还缺什么资料。仅凭参与人数无法判断满意度。
3. **给后续工作排个时间。** 在同一空间打开「任务 → 全部任务」，点「发放满意度问卷」。这项任务由你决定日期。展开「安排执行时段」，把起止时间设为本周的半小时，保存。打开「日历」，点刚出现的时间块，再打开来源笔记。在正文里勾选这项任务并保存，就能在任务的「已完成」视图找到它。
