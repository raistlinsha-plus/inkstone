# Try Inkstone with one Markdown note

[简体中文](README.zh-CN.md) · [Try the browser walkthrough](https://raistlinsha-plus.github.io/inkstone/?lang=en)

Two reading groups met at different venues. You have attendance figures and one follow-up to schedule. This three-minute tour starts with Inkstone open. Reading the chart and scheduling the task work offline. To try a live answer, configure your chat provider first. The browser walkthrough lets you try citations with a prepared answer.

1. **Open the note and check the numbers.** On GitHub, open [the sample note](en/reading-activity.md) and choose **Download raw file**. In Inkstone, choose **My documents → Import documents** and import the downloaded Markdown file into a space. Open the note in **Editor**. Hover over its chart or press Tab to reach the chart toolbar. Switch to **Table** to check the values for Plan A and Plan B.
2. **Trace an answer back to the note.** Choose **Ask about this document** and ask “Which activity had more attendees? Cite the figures for both.” Open the citation and check it against the attendance table on lines 7–10. Plan A lists 120 people and Plan B lists 80. Then ask “Which activity had higher satisfaction?” Line 12 tells you what information is missing. Attendance alone cannot settle that question.
3. **Put the follow-up on your calendar.** In the same space, open **Tasks → All tasks** and select **Send the satisfaction survey**. Its date is yours to choose. Under **Schedule a time slot**, set the start and end to a 30-minute period this week and save. Open **Calendar**, click the new block, then open its source note. Check off the task in the editor and save. You can find it under **Completed** in Tasks.
