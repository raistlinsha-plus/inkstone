## JSON 数组与精度

JSON 树中的大整数应完整显示。编辑 `title` 后，`externalId` 和字面量 `<br />` 应逐字保持；编辑中滚动离屏，再回来时草稿不能静默消失。

```json
{
  "title": "季度汇总",
  "values": [1],
  "years": [2026],
  "externalId": 9007199254740993,
  "literal": "<br />",
  "meta": { "status": "待复核", "owner": "合成演示" }
}
```

## 验收动作

- 在空段输入 `/`，选择“数据图表”；顶端插入菜单应提供相同入口。
- 检查图表、数据表和源码使用同一份数据；保存、重开、撤销和模式往返后仍一致。
- 导出柱状图 SVG 与 PNG，打开文件核对中文、图例、分类与两组数据，不能只以“保存成功”作为结论。
- 只对“季度数据.md”提问，要求使用表格和柱状图比较季度收入；核对引用、单位、数值和保存为文档后的内容。
- 要求一个资料中没有的数字时，应解释资料不足，不编造图表数据。
