# 你好，砚台

这是你的第一份本地知识资料。你可以在源码和可视化模式之间切换，文档始终以 Markdown 保存。

## 这个工具能做什么

砚台是一个本地文本编辑器，也是一份个人知识索引。它支持 TXT 与 Markdown，文档和索引保存在本机。模型服务由使用者自己配置。

## 如何搜索资料

1. 在左侧打开包含笔记的本地目录。
2. 点击「知识库」，选择「开始建库」。
3. 不配置模型也能使用中文关键词搜索。
4. 配置向量化 API 后，再次更新索引，即可使用语义检索。

关键词索引与向量索引由本机 SQLite 管理。清空索引不会删除原始文件。

## 如何获得带出处的回答

在「模型与设置」中填写兼容 API 的地址、模型名称和 API Key。向量化与问答模型可以来自不同服务。

远程向量化会发送所选文本切片；远程问答会发送问题与检索命中的片段。密钥存储于 macOS 钥匙串。

## 文件变化以后

编辑保存后，旧索引会失效。请在知识库中执行「更新索引」。引用关联文档版本，来源变化时会提醒核对。

> 文件自由保存，知识属于你。
