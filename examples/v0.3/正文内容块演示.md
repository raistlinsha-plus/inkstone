# 在正文里组织想法

这是一篇可以直接编辑的文档。把光标放在段落之间，输入 /，或点击上方的 JSON、图表、脑图按钮，即可在原位置插入内容。

## JSON：数据与正文一起阅读

```json
{
  "项目": "Inkstone v0.3",
  "本地保存": true,
  "大整数": 9007199254740993,
  "任务": ["正文编辑", "导入文档", "本地检索"]
}
```

这是 JSON 后的正文。可以继续写中文、插入表格，或修改上方的字段，其他内容会保留。

## 脑图：一张图，一个主题

```mindmap
# 写作计划

- 整理资料
  - 导入本地文档
  - 建立关键词索引
- 开始写作
  - 插入 JSON
  - 组织图表
```

下面是第二张独立的脑图。修改第一张图的节点不会改动第二张。

```mindmap
# 周末计划

- 阅读
- 散步
- 记录灵感
```

## Mermaid：解释一个流程

```mermaid
flowchart LR
  A[导入资料] --> B[编辑正文]
  B --> C[本地保存]
  C --> D[检索与引用]
```

所有内容以 Markdown 文本保存，可切换源码检查、复制或导出。向量化和问答在启用自己的 API 后使用，导入不会自动上传。
