# v0.8.5 macOS 原生验收

使用隔离版 `Inkstone E2E.app` 和本目录的虚构资料。先查 Bundle ID 是 `local.inkstone.desktop.e2e`。隔离版只接受回环 HTTP 模型服务，启动探针只记录 WKWebView 已调用 Rust 启动命令。

## 离线使用

1. 在空文档空间选择「打开离线样例」。确认打开《社区阅读活动》，检索范围为当前文档，检索方式为本地关键词。
2. 执行「阅读活动」搜索，打开标有原文行号的结果。用 Tab 和回车重做一遍，确认窄窗口能够返回编辑器。
3. 切回文档首页再打开同一空间的离线样例，检查列表仍只显示一个样例文件。切换至新建空空间，再运行一次，确认两个空间的样例独立。
4. 用「导入文档」选择本目录的样例并检查完成回执。用系统保存对话框导出 Markdown；再打开导出文件，核对中文标题和正文完整。

## 编辑和重开

1. 在隔离版打开已导入的副本。切换 macOS 简体拼音，输入「读书会」，用候选列表确认，再按 ⌘S。检查一次输入只生成一份文字。切到另一篇与切回时核对光标位置。
2. 用正文工具栏插入日程并打开日期输入控件，检查日期选择、Escape 和 Tab 顺序。
3. 正常退出并重开，确认恢复到之前的文档与视图，已保存文字可读。
4. 打开 VoiceOver。检查样例动作、检索方式、资料来源和返回问答按钮都有可读名称，操作后焦点落在可见区域。

## 带引用问答

1. 若运行仓库的回环模型桩，在「模型与设置」为隔离版填写它的地址，选择问答模型并执行连接测试。
2. 从「AI 问答」开始新对话，添加这份资料，开启「本轮不搜索网页」，询问社区计划开展几场阅读活动。
3. 打开引用、查看原文、返回本轮问答，确认会话和选中引用保留。在宽窗与窄窗各检查一次。

浏览器脚本覆盖的是合成 IPC 交互。验收记录应分别填写系统对话框、中文候选、VoiceOver、回环模型和真实配置服务的结果。
