# v0.7.6 证据选择回归

使用两份冻结的合成样本。前一组沿用 [v0.7.5 的 17 道题](../v0.7.5/retrieval-cases.json)。后一组 [预留样本](retrieval-holdout.json) 使用 7 份新文档、4 个手工 Wiki 主题与 8 道题，在本版实现前固定，和旧题的材料分开。两组的资料和判定均由项目开发过程编写。预留样本指相对既有题集分离，未做外部人工盲审。

原文 oracle 记录必要文档和行号，另记录比较题中禁止引入的第三份来源。测试使用生产 SQLite BM25、Wiki 发布校验、候选融合和上下文选择，保留同样的 6,000 字符预算。验证候选、原文片段进入上下文及其文档身份、哈希、行范围和逐行文本。原始模型、嵌入、重排、Brave 请求次数均为零。
