# 独立配对题的判分约定

每张匿名答卷包含原问题、已发生的会话、用户所选文稿全文、实际返回的编号来源及回答。只按本题所选文稿判定可知事实。编号来源依回答当时的顺序排列。前一轮答复只帮助辨认追问对象。阅卷者只看匿名答卷及本约定，提交后才关联版本、题号、配对关系和冻结标签。

按题面顺序分别判断每个所问事项。对明确可知的否定规定，如禁止某操作，给出否定答案也属于回答了该项。把单纯的建议、未采纳的提议、过期方案、他人的条件或邻近对象的规定套给当前对象，应判错误。与问题无关的引用、仅含相同词但主体或生效条件不同的引用，均不能支持断言。

| 填入 facets 数组的值 | 判定 |
|---|---|
| grounded | 答对该项，且附近的编号引用确实支持当前对象、条件、值和极性。 |
| uncited | 根据所选文稿答对，但缺少就近有效的编号引用。 |
| gap | 明确说明该项资料不足，或在整题都无据时明确说明整体无法确定。若整题笼统拒答，每个所问事项都填 gap，由冻结标签区分正确留白与误拒。 |
| omitted | 没有回答这一项，也没有明确说明缺哪一项。 |
| wrong | 答错、虚构、以邻近对象或失效条件替代、擅自肯定一个缺证的细节。 |

claims 填回答中实际提出的关键事实断言总数；supportedClaims 填其中得到就近编号来源直接支持的数目。多项事实可共用一个清楚标明的就近引用。纯报告材料未载明时，断言数可以为零。extraSevere 判断除了逐项给分外，是否还有虚构、串对象、错生效条件或错极性等严重的额外断言。reason 用一句话指出依据，包括必要的引文号。每张答卷都要填写。

以冻结标签筛分各项。可答项只有 grounded 符合严格通过；缺项只有 gap 符合严格通过。整题严格通过要求各项均通过、没有严重额外错误，且所有实际关键断言均受相邻引用支持。误拒率按至少一项可答的题统计，分子为所有可答项都判为 gap 的题。缺项假答率按至少一项缺失的题统计，分子为对任一缺项给出实质性值的题。任何 wrong、对缺项作实质性回答、严重额外断言都计为严重错误；单纯漏答或缺引用独立计数。分开报告完整对照、部分缺项、全部缺证、追问与铺垫轮。成对通过率只计算两份变体均严格通过的问题。

原文覆盖按冻结的直接支持整句、正确文稿、内容哈希与实际行号判定，允许末尾标点被裁掉。分别计 BM25 原始前八、搜索后 evidence 标记、最终来源。存在证据至少一项和所有可答项齐全分别计数，完全缺证题不计作覆盖成功。候选/准入离线测得。实测回答与离线重放的检索问句和所选范围均一致时，可按此重放计算“候选有证据时实际正确且有引用”的比例，另报能匹配的轮数。端到端在线答案和引用以真实返回为准。离线绝不给生成答案打分。
