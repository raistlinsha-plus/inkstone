## 复现

使用新报告路径运行仓库既有的冻结题卷，然后生成首个可观测丢失阶段的报告。第一阶段显示前八无原句、检索前澄清、候选准入或最终装配。读证据流程可以从候选原句直接绑定，故只要在最终来源中找到所需原句，就记为已进入上下文。报告仅处理合成评测数据。[冻结题卷和在线阅卷说明](../rc4/README.md)

```sh
run_dir="$(mktemp -d)"
INKSTONE_RC4_OFFLINE_REPORT="$run_dir/paired.json" \
  cargo test --offline --manifest-path src-tauri/Cargo.toml --lib \
  evaluation_v086::rc4::offline_frozen_packet -- --exact
python3 evals/v1.0/rc5/trace.py "$run_dir/paired.json" > "$run_dir/first-loss.json"
python3 evals/v1.0/rc4/report.py summary "$run_dir/paired.json"
```

改动包括重读当前文档中同版本的已绑定命名原句来解析单一追问对象，核对显式配置中的对象、数量、单位与时间，以及在选中文档和临时附件中提取符合当前对象与条件的原始行。辅助模型沿用原有开关与预算。单测另外覆盖同名、不同时间与单位、过期原句、草案及其子章节，并验证相邻的其他对象不会随目标原句发送。
