# Inkstone v0.8.3 · 书房同伴

- 左侧提供「书房同伴」。从同伴工作区查看当前角色、桌宠设置、故事、相册及已有经历。
- 墨团可在工作窗口内以 Q 版像素形象陪伴。点击或拖动可以互动，专注时停播主动动效，系统减少动态设置也适用。
- 墨团第一季沿用初见、相识和默契三个成长阶段，提供逐句阅读、续读、分支和 CG 回看。相识章节《捡到一枚书签》加入雨夜书房 CG。
- 角色进度、手札和本机设定沿用已有同伴数据。砚舟和知微仍可选择并使用已有故事与静态角色图。

五个自然使用日的观察列为后续验收。独立 macOS 桌宠小窗在后续预览验证。
