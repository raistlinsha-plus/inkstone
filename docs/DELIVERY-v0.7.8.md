# Inkstone v0.7.8 交付说明

v0.7.8 试点墨团动效。书房同伴仍是可选的本地功能，在问答区启用。砚舟和知微继续使用现有静态立绘、阶段形象和故事。

## 墨团形象和状态

墨团使用像素轮廓、墨绿晕染和暖纸底色。初遇为原有墨色外形，相识加叶纹纸签，同行增加一枚暖金书签细节。形象跟随用户已选择的阶段装束。

| 状态 | 出现时机 | 表情与动效 |
| --- | --- | --- |
| 待机 | 同伴入口空闲或问答结束 | 亮眼，轻微呼吸一次 |
| 陪读 | 当前问答正在处理 | 垂眼看书，轻微点头两次 |
| 里程碑 | 确认的里程碑已计入，或首次处理墨团相识及同行章节 | 笑眼和两枚暖金像素光点，轻跳一次 |

动效可在「同伴设置 → 陪伴模式 → 温和陪伴」中使用。专注、应用中的「减少动态效果」和 macOS 的减少动态设置都提供静态呈现。表情与装束在静态模式中仍可辨认。装饰图形由读屏跳过，工作阶段继续由原有文字提示表达。

## 相识纪念 CG

完成或明确跳过墨团的相识章节后，可在相册打开「墨团 · 纸签下的午后」。已处理相识章节的旧档案会自动获得这张额外插画。原有两张剧情 CG、故事选项和成长进度沿用原档。新图使用本地 SVG，离线可看。[素材说明](../src/companion/assets/README.md)

## 数据与验收

等待、提问、动效和浏览相册均不增加成长。里程碑动画根据已确认操作的结果显示，重复提交和失败不会触发。动效不会发起额外模型请求或读取文档正文，本版沿用已有同伴库结构及备份格式。

同伴定向测试覆盖三种状态、减少动态、关闭陪伴、确认失败与重复提交、阶段解锁及其他角色隔离。五个自然使用日的成长与打扰程度观察需由实际使用记录补齐。
