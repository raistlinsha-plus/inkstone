## 本次关键决策

- 先完成问答preview.0会话底座；第一条角色切片由砚舟改为**墨团**，优先验证像素水墨宠物的辨识与陪伴价值，公共数据结构仍支持三角色。
- UI延续纸色、墨绿、系统字体；像素用于角色轮廓，水墨用于角色内部、书房光影和CG。正文与按钮不使用像素字体。
- 人型角色明确成年、任意用户可选；轻度二次元亲近感来自表情、服饰、动作和逐步开放的台词，不按用户性别配对。
- 成长是主动确认后的有效经历，3条/2日开放相识，8条/5日开放同行；次数、字数、付费调用和连续签到不计成长。
- 事实问答与角色表达分开。固定故事离线可用，每轮新增角色模型调用为0；没有证据时保持拒答。
- 本次不制作完整9阶段立绘与6主CG，不把概念图或同图复用当作阶段资源完成；正式资源签收是v0.7正式版门槛。

原型可本机HTTP预览或离线打开，运行方法见[原型说明](../../../prototypes/v0.7/README.md)。设计工作分支保持本地，是否推送或发布独立于本次设计交付。
