**状态**　beta.2 为构建 10212，beta.3 为本机构建 10213。三组功能的操作入口和验证边界见[本轮交付](../DELIVERY-v1.2.0-beta.3.md)。下列 rc.1 检查保留为候选版任务。

| 版本 | 用户拿到什么 | 评审时怎么判断 |
| --- | --- | --- |
| v1.2.0-beta.2 | 操作空间、输入中文、保存与导入的结果可预期 | 一次完成搜索、改名、取消、导入；文件位置和已编辑内容均可核对 |
| v1.2.0-beta.3 | 空间、文件夹、图片和脑图都有符合其用途的页面 | 分三次看可运行构建，分别走通目录导航、看图问图、两种脑图及跨页面联动 |
| v1.2.0-rc.1 | 同一原生 Mac 构建通过跨页面及历史问题回归 | 中文输入法、键盘、VoiceOver、窄窗、中英文和浅深色均有验收记录 |
| v1.2.0 | 交付通过验收的工作台、双语手册和截图 | 四项 P0 和阻断主要流程的 P1 全部关闭，剩余限制写入发行说明 |

## beta.2 · 统一基础控件，修正文件和草稿去向

**先用「我的空间」做出可操作的样板。** 这一个窗口集中暴露了搜索框、菜单、命名、暗色对比和焦点五类问题。先在这里验收，再把相同行为用到目录、问答、Wiki、任务和日历。

| 工作项 | 交付及验收 |
| --- | --- |
| 搜索与输入 | 搜索图标、文字、清除键共用一个边框；点空白处也能输入。输入、清除、无结果、再次输入都保留焦点。任务快速添加与问答输入框各保留一圈焦点提示。 |
| 行菜单与命名 | 每行一个「⋯」。菜单对齐、在末行自动避让，支持外点关闭、方向键、Enter 和 Esc。Esc 逐层退出，焦点回到触发器。新建标「空间名称／创建」；改名就地预选旧名，重名错误跟随字段。验证中文选词时按 Enter 或 Esc。 |
| 字体、颜色、指针和密度 | 延用空间首页已认可的中文无衬线字体，覆盖日历标题、文档标题、控件与弹窗，代码保留等宽。统一浅色、深色、跟随系统的底色、图标、选中和禁用态，优先修正空间管理的暗色对比。正文用文本光标，拖动手柄才用抓手。控件视觉紧凑，同时保留点击区域。 |
| 文件与任务的去向 | 四项 P0 分别验收：空间导出保留 HEIC 原件；取消 A 文件夹导入后，从 Finder 拖入根目录的文件正确落位；重复加入同图显示已有位置；任务详情使用最新标题和时段「保存并拆解」，失败保留草稿。 |
| 导入和任务目标 | 导入前显示完整目的地及笔记、独立图片、附件、跳过项数量。聊天转任务只提供活动空间内可写笔记，空空间可在确认时创建「任务清单」。任务详情与日历筛选共用中文输入法保护。 |

**放行演示。** 在文件夹 A 取消一次导入，再向根目录拖入照片；对已有照片重复加入；把 HEIC、HEIF、JPEG、PNG 导出后导入空库，比对原件哈希与说明。随后改任务标题并模拟一次保存失败，重试后进入问答，核对标题。四项 P0 中，HEIC 遗漏已由原生后端复现，误移已有图片来自源码核对，两项均须走窗口验收。

## beta.3 · 空间、图片、脑图与日常工作区

本版安排三次可运行的评审，每次都可与原截图直接对照。

### 第一次：从空间找到文件

- **我的空间**成为主区域的管理页，显示空间名称、资料数、最近更新及行操作；页头负责新建和搜索，侧栏负责快速切换。默认空间名为「我的文档」。
- **文件夹是可以进入的位置。** 点击文件夹，中央列出直接子项，面包屑与新建、粘贴、导入共用目标。返回时恢复展开层级、滚动位置和焦点。支持改名、移动、删除空目录，移动后原引用仍有效。已归档空间可浏览和恢复，新写入目标只列活动空间。
- 保留一级栏的图标和悬停文字。键盘聚焦也能读到名称。核对侧栏新建、导入按钮、底部「空间与文件」的占高，以及应用名和版本号间距。在 960 像素宽的窗口按需收起辅助栏。

### 第二次：看清图片，读懂脑图

| 类型 | 默认界面 | 必验动作 |
| --- | --- | --- |
| 独立图片 | 文件名和大图占据主区域，底部放翻页及缩放；单图隐藏无效箭头。「查看文字」直接展示本地 OCR，「分析图片」展示模型与将发送的预览，用户点击发送才发起请求。 | 直接打开 iPhone HEIC/HEIF；在多图空间按明确范围翻页；分析 A 图时切到 B 再返回，找回 A 的待保存结果；保存描述后从问答引用回到这张图。 |
| Mermaid 脑图（`.mmd` 中的 `mindmap`） | 首次打开以画布为主，可明确切到源码或分栏。保留原文件及作者指定的节点形状，根标题按中文字界居中，父子之间用细曲线，同级顺序与源码相符。 | 用原反馈中的「中心主题、分支一、11、22、221、222、分支二」验收。宽窄窗、放大、导出 SVG 时文字都在节点内，其他 Mermaid 图型仍按原语义显示。 |
| 独立 Markdown 脑图（`.mindmap.md`） | 文件标题就是根节点，画布优先；普通笔记的「大纲脑图」保留对照正文的分栏。 | 用 Tab 创建子节点、Enter 创建同级，自动进入新节点命名；中文上屏、撤销、切源和重开后结构一致。 |
| 文档内 Mermaid、脑图、数据图表 | 图成为阅读主体，编辑、缩放、导出等操作在悬停或键盘聚焦时出现。 | 高图最后一个节点完整可达；工具栏不会裁掉图或抢走滚动。图表的数据表、源码及导出入口仍可用。 |

### 第三次：从问答到任务、日历和文档

- **问答工作台与右侧问答。** 会话头压缩成一行。输入区保留连续的书写空间，资料与联网状态靠近发送键。引用、技术详情与次要操作按需展开。窄窗实际检查正文宽度。网页搜索的可见名称、开关方向和读屏播报一致，英文也能完整切换多份候选回答。
- **任务与日历。** 沿用两个独立一级入口。任务页直接添加、勾选和安排任务；日历直接打开上次使用的日历视图。任务详情对齐标题、截止日、状态与执行时段，主要操作突出保存。筛选只保留过滤条件；改期后可撤销，刷新和导出归入日历操作。用一条从聊天创建的任务验证笔记富内容、任务列表、日历展示和回原文均指向同一条。
- **Wiki、索引与同伴。** Wiki 长列表的保存动作和已选数可见，已有全选行为清晰标注筛选范围。索引、Wiki 与目录使用同一资源显示名。桌宠仍为像素形象，故事独立进入；同伴工作区的返回和完成动作说明其对象，并检查日常写作时是否遮挡正文。

## rc.1 · 同一构建的放行清单

| 验收场景 | 通过标准 |
| --- | --- |
| 日常写作 | 在长文中段和列表里用 macOS 拼音连续组词、退选、上屏；首次 Esc 只处理候选，光标与滚动位置稳定。加粗后依次切源码、分栏、正文，返回后仍正确显示加粗。 |
| 空间管理 | 在长列表首行、末行、搜索结果行打开菜单，用鼠标和纯键盘完成新建、重复命名、改名、取消与返回。验证空文件夹、深层目录、归档及恢复。 |
| 资源及问答 | 用已有资料库升级并演练备份恢复；验证原图字节、OCR、视觉描述、检索引用。使用合成图片和已配置的模型，检查真实请求、切图和失败重试。独立核对问答结论及引用。 |
| 布局与可访问性 | 至少覆盖 960 × 640、1280 × 720，简体中文、英文，浅色、深色及跟随系统切换。重点窗口逐项验普通文字对比度、图标对齐、焦点可见、菜单避让、VoiceOver 名称及面板关闭后的焦点。 |
| 回归证据 | 空间搜索、行菜单、命名、Mermaid 脑图、图片底栏分别保留同尺寸前后对照。中文输入、分层 Esc 和任务跨视图同步提供操作记录。 |

## 稳定版 · 用户可见的交付

更新中英文操作手册、产品截图和发行说明，标明支持的图片格式、两类脑图入口、图片发送给模型的时机，以及已知限制。若向公众提供 Mac 安装包，其签名、公证与干净 Mac 安装状态按实际分发条件另行记录。

排期沿用现有两次 Beta 和一个候选版。**beta.2** 优先演示「搜索空间 → 打开行菜单 → 原位改名 → 中文退选 → Esc 返回本行」，同时提供四项 P0 的验证结果。
