# v0.7.0 开发与验收计划

## 开发顺序

以顺序工作包推进，每包提交实现、定向验证和简短回执；完成包之间不反复跑整套模型评测。以下为单人净工作量估算，依赖实际失败处理调整，不承诺墙钟时长。

| 包 | 内容与交付 | 预计净工作量 | 退出条件 |
| --- | --- | --- | --- |
| S1 稳定导航 | 抽共享选择器、名称默认/修改排序、独立最近、偏好、锚点 | 0.5–1 天 | 打开不跳、同名同秒稳定、偏好重开保持、窄窗可达 |
| S2 文档生命周期 | schema4、显式恢复、purge preview/状态机/恢复/失效处理 | 1.5–3 天 | 单篇完整清理、故障恢复与竞争测试通过 |
| S3 体验收口 | 问答头部/范围文案、输入状态、撤下无效果称呼、组件间距 | 0.5–1 天 | 三尺寸和键盘回归通过，已有草稿/停止/导出不回退 |
| S4 资源与自然试用 | 基准像素签收、9 立绘/6 CG、许可清单、自然成长日志 | 制作单独估计；至少 5 个真实使用日 | 无误记/刷取/打断，素材逐项签收 |
| S5 最终验证与交付 | 全量默认检查、真实 API、Mac 原生、迁移/冷启动、说明与安装 | 0.5–1 天，失败另计 | 发布门槛全部满足，明确源码/二进制范围 |

S4 可以与 S1–S3 的自然使用并行，不用改系统日期或压缩门槛代替。美术终稿若未达到约定，应继续候选版，不把“有文件”当签收。S5 集中一次桌面验收；后台构建时锁屏不阻断已可独立执行的任务。

## 定向验证矩阵

| ID | 场景 | 必须结果 |
| --- | --- | --- |
| N01 | 默认名称排序，连开 10 篇再反复开同一篇 | 顺序完全相同，当前项高亮，滚动锚点不跳 |
| N02 | 同秒 updated、同名、2/10/100、长中文 | 比较器全序，numeric 自然排序，两视图一致 |
| N03 | 修改排序打开文件/真正改内容/改名 | 仅实际修改触发修改排序重排；名称排序仅改名重排 |
| N04 | 最近、置顶、搜索、跨空间、重启 | 最近更新独立，置顶不重复，偏好按空间，搜索不静默消失 |
| N05 | 回收站标题、恢复、缺文件 | 标题无副作用；恢复显式，损坏不谎报成功 |
| D01 | 含附件/历史/草稿的合成文档彻底删除 | 对应副本全清；外部原件和其他文档 hash 不变；无撤销 |
| D02 | 非 trashed、跨空间、过期 token、重复 operationId | 服务端拒绝越界；幂等返回原结果 |
| D03 | symlink、相对穿越、外部/共享附件 | 不跟随，不删除清单外文件，明确未开始 |
| D04 | 每阶段 I/O、DB busy、磁盘满、进程退出 | prepared 可回退；committed 只续清；无假成功或资料复活 |
| D05 | 删除与保存/索引/导入/源更新/经历确认/备份竞争 | 排空或 BUSY，晚响应不能写回，备份不含半态 |
| D06 | 来源旧快照、旧 receipt、旧导出/备份 | 旧引用不可新作证据；历史文本保留且注明；旧 token 无效 |
| D07 | 完成返回丢失、pendingCleanup 后重启 | 状态查询正确，无二次删除，未完状态可解释 |
| Q01 | 首问/追问/固定范围/跨空间 | 草稿与候选归属正确，新增范围须新会话 |
| Q02 | 缺资料、索引旧、向量未配、重排失败 | 实际检索方法透明，不捏造结论 |
| Q03 | 停止、继续输入、再生成、当前/全部分支导出 | 停止标记与源码保护保留；新草稿不丢 |
| E01 | 正文→源码→正文，多空行/列表/结构块 | 保留语义与原内容，不出现无意义原始 Markdown 卡片 |
| E02 | 中文 IME、撤销、快捷键、光标插入/取消 | 候选确认不触发发送，编辑焦点/选区可恢复 |
| P01 | 三角色、三阶段、缺图、关闭、故事待读 | 工具能力一致、不主动开故事、缺图仍可用 |
| P02 | 五个真实日期、重复文档/跨角色/删除 | 无重复成长，删除不倒扣；规则按真实事件执行 |
| A01 | 1440/1280/960，200% 文本，键盘/VoiceOver | 文档标题、来源、对话、危险按钮可达，焦点不逃逸 |
| U01 | schema3 升级、失败中断、新版/旧版读取 | 备份可验证，旧版拒绝新库，文档/会话/成长身份不变 |

破坏性和故障注入全部在独立临时资料目录进行，记录原件和邻近文件 hash。原型删除的是内存合成项，不能用作 D01–D07 后端通过证据。

## 原生与真实 API 集中验收

实际生产安装包检查正文/源码各一次中文输入，快捷键、系统导入、Markdown/附件包导出、来源落文、普通退出/重开、窄窗与 VoiceOver。隔离 fixture 的 WebView bootstrap 不替代此项。系统授权若需要，在同一桌面窗口集中处理；不以保存用户 Mac 口令或关闭保护解决。

使用现有用户配置的小型合成资料，先读模型配置与 readiness，不打印凭据；首问、追问、缺项、停止、再生成各一组，三类能力仅测已配置的 chat/embedding/rerank。建立明确请求/费用上限，达到上限停下并报告覆盖缺口，不重复全套既有付费语料。未配置的可选重排验收可保持关键词/向量路径且写明范围；不能宣称其远程接口已验收。

## 发布判断

正式标签要求 S1–S5 完成，无开放 P0/P1；P2 按本稿范围闭环或明确延期经产品决定。保留升级备份验证、完整默认检查回执、合成截图、真实 API 小样、原生清单、素材许可与自然使用记录。运行次数不是质量门槛，只有新改动/失败才扩大重跑。

源码 v0.7.0 稳定标签与 macOS 安装包发行分别判定。后者额外核对签名、公证、跨机启动和升级；本机能启动不能推导陌生机器安装通过。实际创建 GitHub release/tag 或对外发布另按用户明确指令执行。

后续建议：v0.7.1 做真实使用反馈、素材动作与问答首问路径；v0.7.2 测量后优化包体、启动和大空间列表；v0.8 再评估目录树/手动排序、批量生命周期和更强问答工作流。系统桌宠独立立项，不与文件生命周期改造绑定。
