# v0.7.0 详细产品与交互

## 1 产品关系与入口

Inkstone 是本地知识工作台。空间是产品内文档集合，受管理副本是编辑与检索的事实来源；导入的本机原件只是可选更新来源。索引是可重建的派生数据。同伴属于本机用户档案，跨空间共享成长；问答会话仍按空间授权，首次发送固定资料范围。

主界面保持“左侧资料 / 中间正文 / 右侧知识”。左侧顶部为文档、日历、搜索、索引四个任务；下方是空间选择、新建/导入、搜索、文档/最近/回收站。模型和设置收在底部。完整资料管理页与侧栏必须复用同一选择器，避免相同空间两套排序行为。

## 2 文档导航与排序

### 2.1 默认规则

空间文档默认“名称 A–Z”，使用中文 locale、numeric=true 自然比较，`2-` 在 `10-` 前；同名再以 id 升序收尾。非中文标题按相同 locale 比较，不额外重命名。菜单提供名称 A–Z、名称 Z–A、修改时间从新到旧三种模式。最近访问只在“最近”视图出现，不放进空间文档排序菜单。

置顶显示为独立可折叠分组，组内沿用当前排序，正文列表不重复展示；取消置顶回到原排序位置。现有置顶 ID 继续复用。最近视图显示已打开且仍 ready 的当前空间文档，按 opened DESC、id ASC 排列，最多 50 条，完整资料页可查看更多。最近不强制将置顶提到顶部。

| 操作 | 空间文档默认名称排序 | 最近视图 |
| --- | --- | --- |
| 打开/反复点击 | 选中状态变化，位置不变 | opened 更新，可移至顶部 |
| 正文/源码/分栏切换 | 不更新排序字段 | 不作为一次新的打开 |
| 保存内容 | 名称顺序不变 | 不更新 opened |
| 改标题 | 在成功确认后按新名称重排 | 只改标题；opened 不变 |
| 新建/导入 | 放入自然排序位置，定位选中新文档 | 主动打开成功才记录 opened |
| 移入回收站/恢复 | 删除该项/按原规则插回 | 回收站内容排除；恢复不伪造访问 |
| 用户选修改时间排序 | 实际修改后可移动；打开本身不移动 | 不受该选择影响 |

本版不提供“创建时间”排序：现有文档 schema 无可靠 created 字段，不用 updated 冒充。也不临时引入拖拽序号、目录树或文件夹，以免扩大迁移风险。

### 2.2 位置保持与持久化

按 spaceId 保存 sort、pinnedCollapsed；主列表默认文档视图，空间切换回文档，不因为上个空间处于回收站而跳入新空间回收站。最近/回收站为会话内显式选择。返回编辑时保持列表 tab 与 query，重启恢复排序与宽度；不自动恢复搜索词或回收站状态。

刷新数据使用 documentId 作为 React key；记录第一个可见文档 ID 与相对顶部偏移，不按数组下标恢复。只有用户主动“定位当前文档”才 scrollIntoView；打开文档不滚动到列表顶部。当前文档被筛掉时保留正文，显示“当前文档不在筛选结果中 / 定位文档”，不静默清空搜索。

列表项 40px 最小高度，标题单行省略，悬停/聚焦可获完整标题。选中背景与键盘焦点框独立。空查询无结果显示“没有匹配的文档 / 清除搜索”；空空间显示“导入文档 / 新建文档”。从侧栏到完整资料页保留当前空间和排序。

## 3 回收站与单篇彻底删除

### 3.1 页面

回收站属于当前空间，标题旁显示数量。每项显示标题、删除时间、文件类型，“恢复”和更多操作；点击标题打开只读摘要，提供原空间、删除时间、附件/历史数量。摘要默认不渲染旧 HTML 或执行结构块。彻底删除出现在更多操作和摘要底部，红色带文本。

本版不提供清空全部、跨空间删除、自动到期删除和批量删除。空态明确：“回收站为空。移入这里的文档可恢复，除非你主动彻底删除。”恢复成功返回原空间，保留现有置顶状态；外部原件消失也可恢复本地副本。缺少副本的异常项显示缺失原因，不以恢复成功掩盖损坏。

### 3.2 确认弹窗

标题“彻底删除这篇文档？”；显示完整文档标题、空间、附件/历史数量和预计删除大小（未知时不伪造 0）。

- 将删除：Inkstone 副本、专属附件、历史版本、恢复草稿、检索和日历派生数据。
- 不会删除：导入原件；已有问答和手札中的文本；用户导出的文件和备份。
- 解释：“已有来源引用会标记为不可用。此操作无法在 Inkstone 中恢复。若要清理已有对话或手札，请分别管理。”

输入框“输入‘删除’以确认”；主按钮“彻底删除”仅在精确匹配时可用，初始焦点落在取消，Enter 不触发默认删除；Escape 关闭并返回触发项。无需 Mac 密码。处理中禁用重复提交，文案“正在删除…”，进入不可逆阶段后不提供取消。

### 3.3 结果与异常

| 状态 | 呈现与下一步 |
| --- | --- |
| 完成 | 移除条目，轻提示“已彻底删除”；焦点转到下一项或回收站标题，不显示撤销 |
| 预览后被恢复/修改 | “文档状态已变化，尚未删除”，重新预览 |
| 有导入/更新/备份或该文档写入 | “资料正在处理中，请稍后重试”，保持回收站和选择 |
| 确认前校验/准备失败 | “尚未删除”，保留可恢复条目和重试 |
| 已进入删除但部分清理失败 | 条目显示“删除未完成”，仅重试清理，不能恢复或重新编辑；不显示成功 |
| 重启遇到未完成日志 | 启动恢复先核对阶段：提交前回退，提交后继续；状态明确，不静默复活 |
| 结果返回丢失 | 以 operationId 查询状态，不再创建第二次删除 |

删除是副本生命周期操作，不是隐私擦除工具。旧问答快照保留其历史表达并加“来源已删除，无法验证”，继续生成、插入和图表证据校验仍须本轮现存资料；不得把旧快照作为新事实来源。旧备份可由用户主动恢复，但不能被应用自动合并回当前空间。SQLite 空闲页与系统备份不承诺取证级清除。

## 4 编辑与结构块

保留顶栏模式切换与固定工具栏，工具按撤销、样式、强调、列表、链接、插入分组。窄空间时低频项进入“更多”，标题、粗体、列表、插入和模式切换仍可操作。按钮视觉 32px、命中 36px，图标 16px，2px 描边；标题选择器宽 120px。选区改变时样式同步，但不得抢中文组合输入焦点。

正文 `/` 菜单和“插入”使用同一条目：JSON、脑图、Mermaid、图表、日程、表格、代码块。选择后插入当前光标位置，取消保留原光标，结构块后有继续写作入口。插入不触发成长或模型请求。

统一结构块头部 44px、左右 16px，内容内边距 16px，表单字段间距 12px，说明与内容间 8px。图表/脑图初始高度随可用空间约束，长图可滚动和展开，缩放百分比必须为真实值。脑图默认 13–14px，展开不擅自放大字号。源码错误就近展示，不清空原数据；正文和问答共享已校验渲染器。

## 5 知识问答

### 5.1 结构

顶部一行“会话标题 / 会话 / 新建 / 展开”，下一行资料摘要“当前空间 · 首次发送后固定”或“固定范围 · 8 篇资料”，可点开核对范围及索引状态。检索方法与重排在折叠区，不抢占正文。固定范围改变另开新会话，保留旧问题草稿，不能静默用新空间回答旧会话。

同伴栏收为 48px 以下的一行头像、工作状态和手札入口，尚未启用时只显示“添加同伴”次级按钮。新会话空态主句简短，提供 2–3 个清晰问题示例，不将大幅装饰占据主要高度。输入框固定底部，前后区域间距 12px，来源/隐私说明放在范围面板与首次配置，不重复铺满每轮。

### 5.2 本轮生命周期

| 状态 | 用户可见内容 | 数据和操作 |
| --- | --- | --- |
| 新建 | 当前范围、示例、可编辑问题 | 空问题不可发送；Enter 发送，Shift+Enter 换行，IME Enter 只确认候选 |
| 已接收 | 问题进入时间线 | 后端持久接收后才清输入；失败保留问题 |
| 检索 | “正在查找资料” | 显示停止，不显示伪造思考过程 |
| 生成 | 实际流式文本 | 停止可用；新草稿可输入，排队保存状态明确 |
| 校验 | “正在核对引用与图表” | 不将未校验图表作为完成结果呈现 |
| 完成 | Markdown 正文、来源 N、候选 x/y、保存/插入 | 来源属于本候选，先预览再落文 |
| 资料不足 | 明确缺项、可核对来源 | 不用角色语气掩盖缺失，不将推断填成结论 |
| 停止 | “已停止 · 回答未完成” | 保留部分文字；导出未完成结构块为标记源码 |
| 失败 | 具体错误、重试 | 前一轮与新草稿保留，不自动重发付费请求 |

用户向上阅读时不强制滚回底部，出现“有新内容 / 回到底部”；侧栏展开为专用阅读区，回到编辑恢复原宽度和面板偏好。保存成文档默认进入当前空间且再次确认标题；插入先预览并定位当前文档，不覆盖已有正文。

### 5.3 RAG 继续保持的契约

默认 BM25 + 向量融合，重排按已配置且可用的模型启用。仅关键词路径无需向量 API。界面区分关键词可用、向量待建、模型未配、索引旧版本、重排失败降级，不把“配置了地址”展示成“全部就绪”。失败降级需说明实际采用的方法；继续执行前以当前范围和内容 hash 验证来源。正式版做受控冒烟，不同时增加新召回算法或大语料付费评测。

## 6 同伴与成长

保持墨团（宠物）、砚舟（成年男性）、知微（成年女性）自由选择，角色选择与用户性别无关。每角色初遇、相识、同行三阶段，既有成长数值和故事 ID 不改；实际门槛继续由后端现有规则提供，原型数字为演示值。

小同伴默认专注，工作状态由真实事件驱动。点击打开手札，手札分经历、新章、相册、设置。新章只提示可读，不自动覆盖正文；读故事不放宽知识来源门槛。关闭、隐藏形象、减少动态、暂停成长是不同选项，数据影响分别说明；缺图用角色名和文字状态兜底。

正式版撤下无实际效果的称呼设置，保留存量值，不加入新模型请求。要在后续启用称呼，需在角色本地台词模板与输出边界单独设计。角色立绘/CG 保留“像素轮廓 + 墨阶与纸纹”的方向，基准逻辑尺寸、阶段差异、来源和许可逐项签收，详见视觉规格。

## 7 首次使用与验证效率

首次启动默认收件箱与合成欢迎页，提供导入、新建、本地关键词检索。配置模型按聊天、向量、可选重排三组，每组独立连接测试与实际模型名，不把服务商地址写死。保存已有 API 凭据仍走现有钥匙串；设计稿和原型均不包含真实密钥。

开发验收分三层：离线单元/故障测试；无头合成 UI；集中一次可见 Mac 验收。长测试和构建在锁屏期间继续，所有需桌面的项目提前排成清单，避免逐项解锁。隔离测试使用独立资料目录与合成凭据适配；生产仅核对安装与必要真实连接。**不保存系统登录口令，不关闭锁屏/认证来提高速度。** 系统授权弹窗只在确实需要且用户在场时处理。
