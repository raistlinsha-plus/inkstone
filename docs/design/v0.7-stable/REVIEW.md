# v0.7.0 正式版前体验评审

2026-11-06，在本机 `/Applications/Inkstone.app` 的 v0.7.0-rc.3 上检查。打开项目内合成的“排版与组件验收.md”，查看回收站、问答空态与角色选择，未修改正文、发出模型请求、选择角色或删除资料。截图通过原生界面工具取得并逐张打开检查。

## 四步观察

### 1 编辑与文档导航　部分健康

![当前编辑器](../../../artifacts/v0.7-stable-design/native/01-editor.png)

工具栏可见，标题、正文、1 至 10 和 100 至 101 编号处于同一首行，续行按正文边界排列。左侧可拖动宽度，紧凑主导航比早期版本节省空间。这些问题不应作为“仍未修复”重复列入正式版。

选择样例后，列表顺序重新计算。代码中 compact 视图默认按 updated 降序，无排序入口；同秒 updated 相等时比较器返回 0，继承后端 opened 降序。于是只更新 opened 也可能改变相同更新时间文档的位置。**行为已观察，具体成因由代码支持；不能断言每次打开任何文件都会置顶。**

列表混有当前说明、旧副本和评测 JSON；这是当前项目资料组织的实际情况，不应在升级时自动移动或清除。提供名称自然排序、最近入口和完整标题提示即可先解决找文档问题。

### 2 回收站　功能缺口

![当前回收站](../../../artifacts/v0.7-stable-design/native/02-trash.png)

当前空间回收站为空，空态清楚。非空条目的能力不能从此截图推断：检查 `LibraryBrowser.tsx` 发现仅有“恢复”，且标题点击同样调用恢复；Rust `library_trash` 只改状态，不提供 purge 命令。因此确认缺少彻底删除，隐式恢复也需调整。未为截图制造生产垃圾文档。

### 3 问答入口　部分健康

![当前问答](../../../artifacts/v0.7-stable-design/native/03-assistant.png)

空态有三个起步建议，输入框固定底部，会话与检索设置可找到；资料范围与索引计数已存在。仍有三层头部、同伴招募条和大段留白，右栏里真正的资料信息和下一步操作分散。当前为新会话却显示“会话固定范围”，不够直观。正式版显示“当前空间 · 首次发送后固定”，已建会话显示“固定范围 · N 篇资料”。

现有会话、来源与停止功能的回归记录见 [rc.3 报告](../../REVIEW-v0.7-rc3.md)；本轮未发问，不将旧记录算作本次真实 API 结果。新原型以相同的合成方案问答展示层级调整。

### 4 角色选择　结构健康，资源待签收

![当前角色选择](../../../artifacts/v0.7-stable-design/native/04-companion.png)

三角色并列，成年人物年龄明确，自由选择与工具能力相同，关闭和稍后入口可见。概念图协调、纸墨绿与工具风格相容；人物为插画表现，尚不能算严格逐像素终稿。九阶段立绘、六 CG 的文件存在也不等于视觉差异与许可已签收。未点击“相遇”，不改变用户同伴档案。

截图能判断视觉层级和可见操作，无法证明全键盘、VoiceOver、真实中文候选、素材许可或五个自然使用日体验。辅助功能树能读取标题和表格，是基础条件而非无障碍合格结论。

## 问题与正式版处理

| 优先级 | 问题 | 用户影响 | 正式版决定 | 证据 |
| --- | --- | --- | --- | --- |
| P1 | 阅读影响同更新时间文档顺序 | 丢失空间位置记忆 | 名称自然排序默认，Recent 单独视图，稳定 ID 收尾 | 步骤 1；LibraryBrowser 108–114；library list |
| P1 | 无单篇彻底删除 | 无法完成副本生命周期管理 | 预览范围 → 确认 → 可恢复执行日志 → 完成 | 步骤 2 的空态；源码能力核对 |
| P2 | 回收站标题点击隐式恢复 | 不确定操作后果 | 点击看只读摘要，按钮才恢复 | LibraryBrowser 480–481 |
| P2 | 新会话范围文案与阶段不符 | 不知道发送给哪些资料/模型 | 按新建、固定、变更、资料不足分状态 | 步骤 3 |
| P2 | 问答头部层级多、建议按钮偏弱 | 首问分心，结果阅读面积小 | 合并资料摘要、折叠设置、同伴缩为一行 | 步骤 3 |
| P2 | 昵称保存后不参与输出 | 设置承诺与效果不符 | 本版撤下设置入口，保留原数据 | rc.3 已知限制与源码核对 |
| P2 | 部分文档入口仍写 rc.1 或设计阶段 v0.6.6 | 不确定本机和设计适用哪个版本 | 本次修正当前导航，历史设计加快照提示 | README 与中文说明、原 v0.7 设计入口 |
| P1 发布门槛 | 像素终稿与自然多日体验未签收 | 产品卖点兑现不足 | 独立签收清单；不以滤镜或时钟模拟替代 | 步骤 4、资源清单 |

未发现本轮可见界面的 P0。可以开始正式版收口开发，**尚不能发布稳定标签**：排序和删除是新增开发任务，原生输入/读屏、受控 API 和素材验收仍待完成。
