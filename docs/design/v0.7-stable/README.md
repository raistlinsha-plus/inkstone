# Inkstone v0.7.0 正式版设计稿

2026-11-06 · 待实施设计，基线为 v0.7.0-rc.3（e7cd602）。本稿记录设计阶段复核与交互原型。2026-11-07：核心范围已落入 rc.4，实际交付和剩余门槛见[功能收口交付](../../DELIVERY-v0.7-rc4.md)；正式版尚未发布。

正式版的目标是让文档位置可预期、删除结果可理解、问答资料可核对、同伴可安静地长期使用。保留本地文档空间、Markdown 正文、混合检索、多轮问答和三类同伴，新增范围收敛为稳定导航与单篇彻底删除。

## 正式版决策

1. **空间文档默认按名称自然升序**，标题相同以稳定 ID 收尾。打开、阅读、切换正文/源码均不改变位置。用户可明确改为名称降序或修改时间；最近打开另设“最近”视图。
2. 左侧直接提供“文档 / 最近 / 回收站”与排序入口。置顶是可折叠独立分组；搜索不改变排序。选择和滚动锚点按文档 ID 保持。
3. 回收站新增**单篇彻底删除**；标题点击只查看摘要，不再隐式恢复。先展示删除范围，再输入“删除”确认。默认聚焦取消，无自动过期删除。
4. 彻底删除包括受管理副本、专属附件、历史、恢复草稿及派生索引/日历数据；原始导入文件、既有问答和手札文本、用户导出与备份另有明确边界。不能称为全设备抹除。
5. rc.3 的固定会话范围、候选来源快照、停止状态、分支导出继续保留。新稿优化信息位置与文案，不重写检索管线。
6. 同伴保持三角色、三阶段。称呼在正式版先撤下无效果的设置；素材签收、自然多日试用是发布条件。系统桌宠、长动画、更多角色和新格式延后。
