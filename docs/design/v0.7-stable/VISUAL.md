# v0.7.0 视觉与组件规格

视觉基线为本轮原生 rc.3 截图和现有 `src/styles.css`、同伴样片；延续纸白、墨绿、轻分隔。界面保持清晰系统字体，角色承担像素与水墨表达，不把正文变成游戏菜单。

## 窗口与密度

| 可用窗口 | 文档导航 | 编辑/问答 | 行为 |
| --- | --- | --- | --- |
| 1440×900 | 默认 280，可拖 240–360 | 中间 780 左右，知识栏 380 | 三栏；正文左右至少 32 |
| 1280×800 | 默认 260 | 中间约 660，知识栏约 360 | 低频工具进入更多，正文至少 560，否则切任务布局 |
| 960×640 | 默认 240，可收起 | 编辑或问答占剩余 720 | 两栏任务布局，编辑/问答切换，不挤出三条细栏 |
| 低于 960 | 抽屉式文档入口 | 单任务区 | 最小支持宽度另按 Tauri 约束；不得隐藏退出与取消 |

表中为 CSS px，分隔线占用需算入。拖动采用可用宽度约束而非固定三项相加；正文空间不足 560 时主动切任务布局。系统缩放与 200% 文本测试允许纵向滚动，不允许工具和确认按钮跑到窗口外。正文优选宽 680–760，宽窗单栏编辑不无限拉长。

## 字体与节奏

| 部位 | 规格 |
| --- | --- |
| UI | 系统 sans，14/20；次级 12/18，重要错误不小于 13 |
| 正文 | 系统 sans，16/28；标题可沿用现有中文 serif |
| H1 / H2 / H3 | 32/44、24/34、20/30；窄窗 H1 28/40 |
| 标题间距 | H1 下 24；H2 上 32 下 12；H3 上 24 下 10 |
| 段落/列表 | 段落下 12；列表项下 6；marker 与首行同基线，续行对齐正文 |
| 代码/JSON | 系统 mono 13/21；长值换行/水平滚动由组件明示 |
| 脑图 | 默认 13–14，缩放初始适应内容，不用固定大字号填满画布 |

基础间距序列 4、8、12、16、24、32。面板 16，弹窗 24；字段标题到输入 8，字段间 12，区块间 24。不要为每个组件新增相近但不同的 margin。

## 色板与状态

纸白 #FFFEFA、外层 #FAF9F6、文字 #30372F、主操作 #3C6753、选中 #E6ECDD、分隔 #E8E7E0。次级正文建议 #66715F；现有浅灰文字需实测，不将装饰色当文字色。危险文字 #9C3F36 配 #FFF4F1，配“彻底删除”文本；警告配图标和文字，不能只靠颜色。

常规控件圆角 6–8，面板 10，弹窗 12；仅弹窗有柔和投影。UI 图标沿用 Lucide，与产品一致，16px / stroke 2；主导航 18。禁止文本符号代替图标。焦点 ring 2px 墨绿加 2px 间隔，选中背景不能取代焦点。

## 像素水墨素材签收

继续沿用 [v0.7 视觉方向](../v0.7/VISUAL.md)。墨团基础 96×96、头像 48×48；人物 192×288 逻辑画布；CG 960×540 逻辑画布/1920×1080 输出为拟定制作规格。正式签收须检视 1×/2×：轮廓像素簇清楚，墨色层次少而有变化，小尺寸眼睛/纸签可辨；不能只将插画加最近邻缩放或滤镜。

| 验收项 | 数量/要求 |
| --- | --- |
| 阶段形象 | 三角色×三阶段＝9；同脸/物种/配色连续，标志物与姿态可辨阶段 |
| CG | 三角色×两张＝6；对应固定剧情节点，不重复一张图冒充解锁 |
| 缩略图 | 48/72/96px，实际放入 Dock 和相册检视 |
| manifest | 稳定 ID、hash、尺寸、safe area、alt、作者或生成来源、用途和许可状态 |
| 降级 | 图片损坏用角色名和状态文字；仍能关闭/看故事/工作 |
| 动态 | 正式版允许静帧；默认减少动态，后台停止；系统级浮层后续 |

原型复用现有概念图并显式标“预览插画”，用来评审面板位置和尺寸；不作为终稿交付证明。工具图标遵循原组件库，角色素材不手绘为 CSS/SVG 占位。
