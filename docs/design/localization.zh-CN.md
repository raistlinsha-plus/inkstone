# Inkstone 多语言设计 · 从中英文开始

2026-11-22 评审稿。以 v1.0.0-rc.4 为基线，建议先提供简体中文与英语，再按使用需求和校对能力增补语种。这里的版本与数字都是规划目标。

## 用户应当能做什么

例如，一位用户在英文 macOS 上打开中文复盘笔记，问「周五前我要完成什么？用英文回答」。菜单显示英文，回答用英文，点引用仍应回到中文原句。用户选中回答里的一项并保存为任务时，预览显示将写入正文的标题和完整日期，允许在写入前修改。切换回中文界面后，该任务仍然使用用户确认过的标题。书房同伴可在中文或英文界面沿用同一角色、成长进度与已读章节。

| 用户设置或材料 | 建议行为 |
| --- | --- |
| 应用显示语言 | 在「设置 → 语言 / Language」中提供「跟随系统」「简体中文」「English」。选择项以本语言自称显示，设置入口在两种语言下都容易找回。会话草稿和编辑选区在切换后仍可继续使用。 |
| 日期、数字与时间 | 跟随系统的地区格式，继续使用任务或日程自身的时区；显示语言切换不会挪动会议，执行日期和到期日期仍各自保存。自然语言里的“下周五”确认时显示年月日；有歧义的短日期请用户确定。 |
| 模型回答语言 | 优先采用本轮明确要求的语言，再用用户已选的回答偏好。默认「随提问」；短追问可沿用会话语言，仍不明时使用界面语言。改写、翻译遵循本轮目标。历史消息、记忆和已保存回答保留原文。 |
| 文档、引用和 Wiki | 材料保留原语言及版本。引文按原文逐字核对；需要译文时在引文之外标注「译文」。Wiki 的输出语言在生成时确定，用户切换界面只更新按钮和状态文案；跨语言重编写另起一次可审阅的更改。 |
| 同伴 | 操作、权限和记忆提示跟随界面；角色台词、CG 说明与剧本用随应用提供的本地语言包。角色设定给译者提供人称、语气、词汇表和上下文，关键剧情需人工校对；同伴不会因用户切换语言获得额外的资料或记忆。 |

## 现有实现与工程落点

公开仓库已有中英文介绍，当前 README 标明桌面界面为中文。入口 HTML 固定 `zh-CN`，日历引入 `zh-cn`，多个组件直接指定日期格式。关键词索引用 jieba 搜索分词并做小写化，读证据中已有针对中文问题的提示和关系匹配。英语界面、英语事实问答和跨语言检索各有独立的验证工作。[README](../../README.md) · [WebView 入口](../../index.html) · [日历](../../src/calendar/CalendarBoard.tsx) · [本地索引](../../src-tauri/src/db.rs) · [证据选择](../../src-tauri/src/evidence_reader.rs)

1. **启动与切换。** 增设统一 locale provider。设置保存 `system` 或规范化的语言标签；首次安装按系统语言偏好顺序匹配候选语言。明确区分简体和繁体，英语地区变体共用英文资源并保留地区格式。当找不到已支持语言时给新用户英文回退和醒目的语言选择。升级现有中文用户时保留简体中文并允许改为跟随系统。在编辑器和会话组件挂载前读取偏好，然后设置 HTML `lang`、窗口可本地化标题、日历控件、通知和无障碍名称。切换时仅刷新资源绑定，避免通过销毁编辑器刷新整页。[现有外观偏好](../../src/platform/appearance.ts) · [模型与设置](../../src/SettingsModal.tsx)
2. **消息资源。** 简体中文、英语分别打包静态消息目录。按模块组织稳定的消息键，TS 构建校验键、命名参数与复数分支；开发时显示缺词，运行时回退到完整目录。按钮、描述、错误恢复、占位、工具提示、屏幕阅读器名称均纳入清单。整句翻译，支持占位符换序；数字、复数、日期和排序交给 `Intl` 与已有日历适配层。日期显示和界面变化以外，保留 ISO 持久化与原始来源行号。任何新增本地化依赖先复核上游许可证和打包大小。
3. **Rust 与系统窗口。** 为常见可恢复错误返回稳定 code 与结构化参数，由 UI 选择文本；迁移期兼容旧字符串，模型或操作系统的诊断原文在详情中单列。将原生菜单与应用自有弹窗标题纳入打包资源核验。macOS 控制的打开/保存或系统认证面板按系统行为验收，手册明确说明。CLI JSON、文档格式、SQLite 键和稳定标识保留协议值，终端帮助与机器输出分别测试。[macOS 应用元数据](../../src-tauri/Info.plist) · [CLI 接入说明](../EXTERNAL-TOOLS.zh-CN.md)
4. **模型、RAG 与记忆。** 内部协议字段、原句编号和引用格式在各语言中稳定，提示词内单独传目标回答语言。筛选、重排与选句要分别覆盖中问中答、英问英答、混排与跨语问答。切换界面不会触发翻译、重新生成向量或额外远程请求。先评估现有 BM25 与已配置嵌入模型；词形或日文分词确有缺口再变更索引器。若调整分词，给索引算法版本号并从文档增量重建，保留可读的旧索引直到新索引完整。引用跳转始终用原文版本、行号与授权范围。任务提取和对话/同伴的上下文查看使用同一套来源标签；为用户展示翻译时明示，语言切换保留上下文归属以及原有的记忆权限。
5. **同伴内容。** `characterId`、章节、解锁与 CG ID 共用；语言包只承载名称、台词、选择项和替代文本。用稳定段落标识来恢复阅读位置，旧书签的页码可迁移到最接近的段落。带文字的插画补充等价字幕或需授权的译图；旧版角色名称和已确认经历继续可读。翻译缺失的试验语种标出原文语言，不把未翻译的剧情计入翻译完成率。[故事目录](../../src/companion/stories.json) · [阅读器与书签](../../src/companion/StoryReader.tsx)

## 版本安排和验收

| 阶段 | 工作范围 | 建议退出条件 |
| --- | --- | --- |
| RC.5 期间，设计与小试验 | 盘点 UI、Rust 返回文案和剧本。用隔离原型走一次设置切换、英文日历与引文跳转。准备翻译词表与中英原文测试样本。保留 RC.5 的问答冻结题及约定配置。 | 产出按界面分组的词条清单、现状差距和工作量。原型在 macOS 窗口可切回原语言。 |
| 1.1 Alpha 至 Beta，主路径双语预览 | 新任务、改期、求助与行动项提取自第一天使用消息键。Beta 贯通首次使用、空间与文档、模型设置、提问和引用、任务与日历，并给出英文快速开始。 | 两种语言各自完成「从对话选两项 → 存入 Markdown → 安排一项 → 从日历回到原句」；无翻译填充符、焦点丢失、未确认写入、跨空间泄露。公布其余仍为中文的界面与剧情范围。 |
| 1.2，完整简中/英文界面 | 补齐 Wiki 管理、索引、导入恢复、错误与授权、全部同伴操作和首季剧情；补英文操作手册，GitHub 明示各语言的 UI、剧情及检索评测状态。 | 两目录键和参数完整率 100%；发布范围内用户可见的系统文案缺译为 0。两种语言分别跑原生主流程和用户体验抽测。英语回答和跨语言检索的效果单独报告，未过门槛的能力保留实验标签。 |
| 后续语言包 | 优先候选为繁体中文、日语、西班牙语，其余如法语和德语依反馈排期。每次只扩大一个有使用者和校对者的包。RTL 语言需另做双向排版和混写编辑验收。 | 建议有至少 5 名目标用户愿意试用、至少 1 名母语校对者维护词表、连续两个候选的语言回归通过后进入正式选择器。繁体需独立术语校对；日语需测专名、假名和混合检索；西语需测性数与复数。 |

**验收分母。** UI 覆盖按本次清单中的键计数并人工检查截图，剧情覆盖按章节/角色计数，检索效果按题目计数。正式声明某一语言的有据问答达到产品门槛前，建议为该方向准备至少 40 道由目标语言使用者编写的冻结题，涵盖同名实体、追问、缺证与引用；沿用既有人工正确率 ≥90%、关键引文支持率 ≥95%、严重错误为零的标准。中问英料与英问中料单列，报告题数和绝对得分。模型、嵌入、联网配置随评测披露。[既有放行条件](v1.0.zh-CN.md)

**回归样例。** 在 960×640、125% 缩放和明暗主题下检查长英文按钮、中文输入法确认、混合脚本字体、键盘及 VoiceOver。给英文长文本做伪本地化拉伸；日历用美式与英式短日期、月首、夏令时的重叠时段跑用例。离线切换、重启、草稿未保存时切换、会话有在途回答时切换，以及备份恢复后切换，均核对文档正文、来源引文、任务 ID、同伴进度的前后状态。将翻译资源加载计入首屏基线，记录打包体积变化。
