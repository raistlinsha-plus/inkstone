# Inkstone v0.7.7 交付说明

## 从第一份资料到回答

文档空间的「从资料到第一条回答」标出当前需要完成的一步。按需复制导入资料、建立关键词索引、配置聊天模型，然后点击「打开问答」。输入框获得焦点，回答下方可以展开「本轮资料依据」并打开相应来源。源文件版本、行号和已保存的历史引用仍按现有规则核对。

独立问答里的「添加资料」区分浏览和选择。浏览空间时可以筛选文档标题。勾选文档后只使用勾选范围，点击「使用整个空间」才会加入整个空间。选中的空间和附件持续显示在输入框上方。取消最后一篇文档会移除该空间。切换会话仍可恢复已保存的草稿、资料和本轮网页限制。

问答生成阶段在回答上方显示一条状态。点击停止后进入「正在停止生成」，当前按钮会忽略重复操作。重试原问题沿用原来的轮次和资料范围，输入框中未发送的下一问仍可保留。自动联网继续由模型按题判断，输入框保留「本轮不搜索网页」。

## 首次整理 Wiki

打开「知识 Wiki」，按提示依次选择范围、整理和审阅。设置未保存时，先保存范围再整理。待审阅改动提供快捷入口和原文摘录，检查后由用户发布。发布后打开生效页面，可继续检查原文位置。

## 验收范围

合成用例覆盖浏览空间时无隐式选中、资料范围草稿恢复、阶段和停止、原问题重试、Wiki 范围授权与发布后的原文定位。真实 Brave 服务需要网络可达和已授权账号，本机直连探测在收到 HTTP 响应前超时。真实联网问答应继续单列验收。[上一版联网诊断](DELIVERY-v0.7.5.md)
