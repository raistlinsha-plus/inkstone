# Inkstone v0.8.5 · 首次使用与本机升级

在文档空间首页打开离线样例，试用本地关键词搜索，从结果返回原文。样例使用虚构资料，关键词建索引和搜索在本机进行。导入自己的文档后可以用同一检索入口。

AI 问答在「模型与设置」配置兼容模型后使用。可以给本轮添加文档、提交问题、核对引文并返回该会话。模型服务接收本轮适用内容，公开网页搜索有独立设置。

## 本机可靠性

- 编辑器读取和保存每个空间的上次文档、视图和位置。失效的本机视图偏好不会妨碍打开文档，切换文档时从目标文档的位置开始。
- 本机升级有独立预检步骤，核对版本、提交、归档和签名。正常退出后建立完整回退快照，在单独工作副本校验便携备份，再原位替换并核对新应用及资料。项目文档同步沿用受管理导入和来源更新，保留历史和冲突保护。
- 继续沿用现有资料格式。旧版升级须从支持的版本建立快照，回退时恢复匹配的应用与资料。源码预览发布附带归档和 SHA-256 校验文件。

## 验收范围

- 合成浏览器覆盖离线样例、检索、结果打开原文、独立问答的范围和引用返回，以及首次使用时的设置路径。
- 本机打包、升级、回退路径、原生启动与测试机首次安装分别记录。中文输入法、键盘导航、系统文件对话框、日期控件与 VoiceOver 需要可见的系统交互。真实模型、独立质量评测与跨机测试按各自结果记录。
