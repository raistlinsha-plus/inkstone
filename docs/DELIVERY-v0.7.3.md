# Inkstone v0.7.3 交付说明

在 [v0.7.2 的知识 Wiki 和自动联网](DELIVERY-v0.7.2.md)基础上，v0.7.3 增加独立 AI 问答工作台。可以直接聊天、改写、翻译或解释，再按本轮任务明确选资料。原有文档侧边栏继续用于对正在阅读的文档或空间提问。

## 第一次使用

1. 在「模型与设置」启用兼容聊天模型。点击左侧「AI 问答」，创建独立会话。无需先建立文档空间或索引，就可以发送「把下面两句话改成简短的项目通知」。
2. 要用本地资料时，从输入框「添加资料」选择一个受管理空间。可以检索整个所选空间，或明确勾选该空间至多 5 篇文档。添加当前受管理文档也会明确显示所属空间和选择。
3. 要用尚未入库的内容时，从同一菜单添加 UTF-8 文本附件，支持 TXT、MD/Markdown、JSON、MMD。单文件上限 2 MiB，每轮最多 5 份，每个会话最多保留 12 份。所有会话在本机问答数据库中合计最多保存 32 MiB 附件文本。附件复制到本机独立会话中，可以复用或删除，原文件及文档空间保持原样。
4. 发送前查看所选资料标签。发送时记录本轮选择，回答中显示用到的原文、附件或网页，以及未进入本轮证据的部分。需要时点击引用核对。用明确的保存操作把结果写入文档空间。

## 问答怎样使用资料

- **直接作答。** 未选择本地资料且本轮未取网页时，走通用对话。有限的历史问题、上轮回答摘录和用户启用的全局表达偏好可以为生成提供语境。普通解释和写作允许无引用的 Markdown 回答。上轮回答仅作编辑和追问语境。
- **使用选定资料。** 明确选择的短文本可直接读取，较长文档或附件按相关片段进入上下文。选择整个空间时，使用该空间可用的关键词、向量、Wiki 和可选重排能力。来源选择限定在本轮。文档和附件在调用模型前与生成结束时重新检查状态。
- **核对公开信息。** 仍需在设置中授权 Brave Search 和提供独立密钥。聊天模型仅以当前问题规划是否搜索，Brave 只收到通过范围校验的查询。网页正文取证可与本轮明确选定的资料结合。证据不足时提示范围和限制。实时信息需要实际取得公开来源才能表明已核验。

独立会话和各文档空间的会话使用隔离标识。打开另一个空间不会隐式扩大独立问答的资料范围。会话库新增附件与每轮来源选择，支持本机持久会话及新格式快照验证。聊天请求会把问题和用于生成的资料发送至用户配置的服务。附件副本随会话保存在本机，既有回答中的历史引用记录可能在移除附件后继续存在。

## 验收边界

- 本版以 macOS Apple Silicon 源码预览交付。问答、附件选择和来源展示有本地逻辑与合成界面检查。真实模型表现随配置变化，实际 Brave 帐号的端到端路径未验收。
- 图片、多媒体、PDF、DOCX、OCR、同时跨多个空间的选取、任意代码执行和动态网页抓取列入后续范围。资料范围或字符预算可能限制完整性。公共来源链接可访问时，仍建议打开原文核对时间和语境。
- 书房同伴延续已有的独立设置和经历管理。本版范围集中在知识整理、来源与问答，新的动效、表情差分和阶段美术继续列在后续计划。
