# Inkstone v0.8.6 · 有据问答

指定本地资料后，回答以指定资料为依据。找不到足够的本地证据时会说明缺口，即使搜索到了公开网页，也不会用它们代替指定资料。没有指定资料的通用问答仍可直接回答，必要时也可按原有授权搜索公开网页。

## 用法

1. 在「AI 问答」中添加资料，或从文档工作区对当前空间或文档提问。
2. 回答标明直接回答、来自本地/网页或未能核实。「本轮依据」打开传给模型的原文片段；条数表示提供了多少段材料。
3. 对标记为待核对或与来源不一致的具体结论，可以直接打开对应引用。数字、单位、日期和否定条件的规则检查只是辅助，仍需核对语义和来源版本。

## 联网边界

Brave Search API 使用固定的 HTTPS 地址，可以沿用系统代理。对搜索结果网页取证时继续直连，并执行 DNS 和连接地址检查；搜索摘要不能直接作为证据，未取得可用网页正文时说明缺口。

参考 [Brave Search API 认证说明](https://api-dashboard.search.brave.com/documentation/guides/authentication)和 [reqwest 系统代理行为](https://docs.rs/reqwest/0.12.28/reqwest/index.html#proxies)。

## 评测与发行

- 将资料召回、证据是否进入上下文、回答正确性、引用是否支持陈述以及合理拒答单独统计。留出集和真实服务结果见[独立评测目录](../evals/v0.8.6/README.md)。
- 本版不改变资料或会话存储结构。沿用 v0.8.5 的升级预检、快照、便携备份、原位升级与回退流程。
- GitHub 提供源码预发布。签名公证和第二台干净 Mac 安装验收属于公开安装包的发行条件。
