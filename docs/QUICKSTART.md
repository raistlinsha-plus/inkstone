# 从源码试用 Inkstone

v0.7.1 可从工作台的「从资料到第一条回答」依次打开导入、索引、模型设置和问答。问答支持当前空间或全局回答偏好，也可预览后加入一条历史问题作为背景。详见 [v0.7.1 使用路径](DELIVERY-v0.7.1.md)。

适用版本：v0.7.0-rc.4。目标为 macOS 13+ Apple Silicon，应用界面目前为中文。本次准备的是源码预发布，没有可供普通用户一键安装的公证安装包。

## 先体验文档，再连接模型

1. 安装 Apple 命令行开发工具及项目指定的 Node 24.14.0、npm 11.9.0、Rust 1.99.1。精确基线见 `toolchain.json`。
2. 克隆仓库并运行：

   ```sh
   git clone https://github.com/raistlinsha-plus/inkstone.git
   cd inkstone
   npm ci --registry=https://registry.npmjs.org
   npm run desktop
   ```

   若要复现特定版本，请在 Releases 中选择对应源码或标签，再执行安装；标签是否存在以实际发布列表为准。本文与演示对应 v0.7.0-rc.4，所选源码版本以 `package.json` 为准。

3. 新建文档空间，复制导入 [阅读活动方案](../examples/v0.7/阅读活动方案.md) 和 [内容块演示](../examples/v0.7/内容块演示.md)。导入后编辑产品副本，原件保留。
4. 切换“正文/源码”，查看图表、JSON、Mermaid 和脑图；修改一处后保存，再切换查看。关键词检索与编辑不需要模型 API。
5. 在“索引”核对当前空间的关键词准备状态；在检索面板选择关键词模式，搜索“阅读活动”。不要为第一次查看文档就启用收费模型。

首次下载依赖与编译需要网络及额外时间，不承诺“5 分钟安装完成”。若提示工具链版本不符，请按项目基线安装，不必覆盖你原来的工具链。

## 使用自己的模型 API

进入“模型与设置”，分别配置问答与向量模型的兼容地址、模型名、密钥。可选重排使用独立的 Cohere 兼容端点。服务商是否提供这些接口、模型名和费用以你的账号为准。远程地址使用 HTTPS，本机回环服务可使用 HTTP。

模型密钥通过 macOS Keychain 保存。第一次使用可能需要系统授权；应用不保存系统登录口令。

选择要索引的文档后建立向量索引，再按需求选择 BM25＋向量及可选重排。向量化会发送所选片段，重排会发送问题及候选摘要；问答会发送问题、当前证据及有限历史用户问题。只有关键词检索不调用模型。

用阅读活动示例尝试：

- 首问：“比较两种阅读活动的参与人数。”核对回答是否对应 120、80 及差值 40，再打开来源。
- 追问：“哪个方案的满意度更高？”资料没有提供满意度，正确行为是说明缺少依据。
- 保存有用回答为文档，继续编辑；不要把上述示例当成所有模型都能保证通过的质量评测。

## 可选书房同伴

默认可保持专注写作，自愿开启墨团、砚舟或知微。固定故事离线可用；确认有效工作经历后逐步解锁阶段内容。当前形象为静态候选插画，尚不是完整动画桌宠。故事、经历卡和旧 AI 回答不会成为事实检索依据。

## 独立本机应用与反馈

`npm run bundle` 生成独立应用。日常只保留 `/Applications/Inkstone.app` 一个入口；构建包、测试包与资料目录分开管理，参见[本机更新约定](LOCAL-INSTALLATION.md)。当前包使用临时签名，Developer ID、公证及跨机验收尚未完成。

遇到问题请提交版本、macOS/芯片、操作步骤和最小虚构文档。不要上传真实资料、密钥或私人备份。候选状态、质量限制见 [已知限制](KNOWN-LIMITATIONS.md) 和 [本轮发布审查](GITHUB-READINESS-v0.7.md)。
