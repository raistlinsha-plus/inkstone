# Inkstone v0.9.0-beta.2 · 首次使用

首次体验从文档开始。在空间首页选择「用示例体验」或「导入我的资料」。样例有独立空间，可以先体验关键词查找、打开原文与模拟有据回答。界面标明模拟数据和回答。自己的笔记保存在所选择的文档空间。

用自己的资料提问时，选定资料与草稿会跟随本轮。需要连接服务时，可先设置问答模型，再回到同一个问题。向量检索、重排和网页搜索按需配置。

验收从空资料目录开始，切换真实资料空间和样例空间，核对样例可重复打开并维持原有文档。带问题和资料选择打开设置，分别检查取消、保存和重新打开。
