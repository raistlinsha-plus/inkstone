# Inkstone v0.8.2 · 文档与 Wiki

- 文档工具栏统一格式、插入和键盘操作。窄窗可以通过更多菜单访问溢出动作。编辑器继续支持 Markdown 正文、源码和分栏。
- JSON、Mermaid、脑图、日历和图表沿用原有 Markdown 格式，统一正文中的间距、组件边界和常用操作。
- Wiki 资料可筛选，当前待审、已发布与整理历史分别展示。发布确认显示核验证据与来源。缺证候选仍可只发布核验摘录。从窄窗的 Wiki 原文入口可以打开可见编辑器。
- 在「模型与设置 → 工作台外观」切换跟随系统、浅色和深色。编辑器与 Wiki 使用统一颜色，工作台已使用这些颜色的部位一并切换。旧设置页和部分嵌入式图表保留自身颜色。
