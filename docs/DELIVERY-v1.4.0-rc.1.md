# v1.4.0-rc.1 · 在对话里用图，把结果存回项目

本机候选构建 10222。想核对照片和会议纪要时，在通用问答里添加一张空间图片和一份笔记。想制作一张新图时，点输入栏旁的「生成图片」，使用自己的服务，查看结果后选定空间和文件夹保存。

| 本机版本 | 主要变化 |
| --- | --- |
| 1.2.0-rc.1 · 10219 | 快速拖动脑图节点能按松手位置落位。空间在搜索结果中改名后，焦点返回改名的行。 |
| 1.2.0 · 10220 | 「那，周三？」能继承前一问的对象并核对时间。升级备份增加完整恢复演练。系统精确 OCR 失败时尝试快速识别其支持的文字。 |
| 1.3.0 · 10221 | 在同一轮使用图片与笔记。OCR、已保存描述、向模型发送 JPEG 预览分别选择。发送画面前可核对模型和服务。 |
| 1.4.0-rc.1 · 10222 | 生图工具从问答或资料库打开，支持独立的服务设置、预览、修改提示词及重试。确认保存后才入库。同一目录重复保存复用相同图片，选另一个目录另存一份。 |

最左侧的图标始终从「文档」开始。文档目录和任务筛选栏共用同一条分隔线，拖动分隔线可以调宽。点击窗口左上方的侧栏按钮可分别收起文档目录或任务筛选，切回来时会记住各自的状态。打开「日历」直接显示整幅日历。


## 验证和适用范围

在本机 Apple Silicon Mac 上核对了中文长文组词和上屏、加粗跨视图、快速拖动和 16 种导航状态。恢复演练使用私有临时目录。两种语言的选图与生图流程可用鼠标或键盘操作。在 960 和 1280 像素宽的中英文窗口中，文档和任务侧栏默认宽度均为 272 像素，七个任务筛选都可操作。切换和折叠时一级菜单图标的坐标保持一致。

真实服务抽样使用合成图文。gpt-4.1-mini 在一轮里读出图片上的「INKSTONE RESEARCH 2026」和笔记里的「MICA-71」，分别引用了正确资料。前后版本另用同一组两问核对指代追问。实际发生 6 次文字请求（包括重复运行的旧版两问）及 1 次看图请求。冻结题集的离线证据覆盖仍为 21/53，追问 2/13。这次抽样尚不足以评价整体回答正确率。

生图请求、预览和目标文件夹保存使用本地模拟服务验收。尚待用户填写实际开通的生图模型 ID。服务须支持兼容的 images/generations 接口并返回 Base64 图片。当前候选为本机签名版本，跨 Mac 人工试用、盲评和公开安装包的签名公证另行验收。
