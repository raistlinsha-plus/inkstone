# Inkstone v0.7.1 本机交付

2026-11-07。从 v0.7.0-rc.5 开发线交付，覆盖首次使用和可控记忆。本机日常入口为 `/Applications/Inkstone.app`，Apple Silicon 临时签名构建。公开发行记录见 [GitHub Releases](https://github.com/raistlinsha-plus/inkstone/releases)。

## 使用路径

- 工作台的「从资料到第一条回答」提供复制导入、索引、模型设置和问答入口。已有本地目录仍可打开。建立本地索引后可离线关键词检索，生成回答需要启用聊天模型，向量与重排是可选能力。
- 「问答 → 回答偏好」支持当前空间与全部空间。用户可保存、停用、删除结构、篇幅和原单位选项，当前空间启用项优先。旧自由文本只在迁移面板内展示，由用户选择受控选项确认采用或忽略。问答输入区可停用本轮偏好。
- 「问答 → 会话 → 选作背景」从当前空间会话的活动分支选取一条旧用户问题。预览最多 400 字，确认后可在输入区移除。问答发送时再校验范围、活动分支和问题摘要，引用只使用本轮文档。模型与检索信息和本轮使用的记忆分别可展开。
- 「书房同伴 → 设置 → 回顾最近一起完成的事」默认关闭。启用后，显示当前空间、当前角色近 30 天最近的一条有效经历。手札可按角色和起始日期筛选，最新 30 条可检查来源状态。打开来源时再次校验原文版本。编辑或删除卡片文字后，已确认的成长保留。

## 数据与升级

问答库从 schema 1 升至 2，使用事务增加受控偏好和迁移状态表。候选只保存应用过的偏好标识、修订号、历史轮次引用及省略说明。历史背景不作为检索词，不重放旧回答。原有连续追问继续采用原本的活动分支逻辑。本轮资料与当前问题优先分配上下文，新增块总上限 800 字符。组装发生在本机，随原有一次聊天请求发送。没有证据时沿用原先拒答或澄清路径。

同伴回顾由已确认经历卡与去重账本关联，重新校验空间、文档 ID 和内容哈希。回顾开关使用向后兼容的默认值，库 schema 仍为 1。原有 catalog 4、索引 3、备份格式 2 维持。v0.7.1 可以验证并恢复旧会话库快照，使用旧程序回退需要搭配升级前快照。更新前关机快照、原应用压缩档及已验证的 Inkstone 备份位于主仓库私有构建产物。

## 回归结果

- 全量 `npm run verify` 通过，前端 53 文件 285 项、Rust 182 项通过，6 项显式工具或远程评测保持默认忽略。覆盖偏好隔离、旧库迁移、历史摘要预算、活动分支失效、同伴回顾和双库快照。
- 合成浏览器回归覆盖 1440、1280、960 窗宽的问答与编辑入口、草稿和停止、来源、文档排序、回收站及新建/导入对齐。
- 本机 WebKit 原生窗口实际完成当前空间偏好的保存、重新读取和删除，同伴回顾的启停，以及交付文档打开。会话历史和本轮停用入口可用。
- Apple Silicon 应用完成构建并通过签名及版本检查。旧安装目录身份与生产资料目录保留。升级前产品备份验证通过，包含 658 个归档条目。
- 真实模型、VoiceOver、原生中文 IME 和多位首次使用者试用为独立验收项。受控称呼与次要编辑器样式延后。v0.7.2 继续处理 RAG 质量和独立评测，v0.7.3 继续处理同伴动效。

更多发布前限制见 [已知限制](KNOWN-LIMITATIONS.md)。当前应用使用本机签名。
