# v1.2.0 · 写作、脑图与追问回归

2026-11-28 在本机 Apple Silicon Mac 上验证。复测使用合成文档与试验资料库。

| 日常操作 | 复现与结果 |
| --- | --- |
| 在长文中段用中文输入 | 在原生 WKWebView 中创建 180 段正文，定位到中段的「2、Agentic模式」。通过系统文本输入协议写入标点，标记拼音，调用编辑器实际草稿读取接口，然后确认候选词。原段变为「2、Agentic模式：拼音」，光标留在该段，末段内容正确。 |
| 正文中的加粗 | 在上述流程之后依次切换源码、分栏和正文。回到正文时，小节标题具有加粗标记，已上屏的文字完整。 |
| 快速拖动脑图节点 | 模拟按下后只有松手坐标、没有中间移动事件的拖动。原行为写入位置 0 次。修订后，移动 40 × 10 像素的用例在 100% 缩放下准确写入一次位移。小幅抖动仍按点击处理，取消拖动不写入位置。编辑、脑图和输入法专项共 25 项通过。 |
| 追问变更星期 | 在「阅览室周一几点开门？」后输入「周三？」或「那，周三？」，现在会查询同一阅览室周三的开放时间。缺少前情时请求澄清，含有多个星期的句子继续走完整问题处理。追问出处与范围专项 10 项通过。 |
| 备份与恢复 | 9 项原生维护测试通过，覆盖资料正文与历史、附件、草稿、并发写入，以及损坏或不完整备份的拒绝与恢复失败后的清理。 |
