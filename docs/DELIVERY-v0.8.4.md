# Inkstone v0.8.4 · 浅深配色与可读性

在「模型与设置 → 工作台外观」选择跟随系统、浅色或深色。外观即时生效并保存在本机。

## 本轮改动

- 文档、问答、检索和 Wiki 共享正文、侧栏、输入与浮层的语义配色。统一菜单悬停、键盘焦点、选中标记、表单占位提示和危险操作的表现。
- 调整问答开场、资料范围选择、文档操作菜单、搜索结果、模型设置与导入弹窗。
- 正文日历与独立日历的月份、今日、选中日期和日期输入随主题变化。书房同伴的资料卡、故事入口、相册和桌宠菜单使用应用主题，CG 保留插画原色。
- Markdown 与 JSON 源码保留主题化语法高亮。Mermaid、脑图和 ECharts 的本地沙箱预览跟随应用主题，SVG/PNG 默认使用浅色画布。图表用纹理、线型和点型辅助区分系列。

## 复查路径

1. 分别在浅色和深色打开问答资料选择、文档菜单、搜索与模型设置。按 Tab 核对焦点，再检查悬停与已选中状态。
2. 打开含日历、脑图、Mermaid 和图表的示例，切换主题后检查画布、文字和操作。核对图形导出与源码内容。
3. 打开 Wiki 和书房同伴，检查状态标签、故事入口、相册和桌宠菜单。切回跟随系统后，复查主题即时切换。
