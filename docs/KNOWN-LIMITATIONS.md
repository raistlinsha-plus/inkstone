# Known preview limitations

The current development version is v0.8.4 for macOS 13+ on Apple Silicon. The published source candidate is v0.8.0-rc.2. Developer ID signing, notarization and cross-machine installation are pending. Native Pinyin candidate confirmation, VoiceOver reading and long-running performance checks require dedicated acceptance. Synthetic-browser checks cover selected workflows with fixture IPC. [Candidate delivery](DELIVERY-v0.8.0-rc2.md) · [Published artifacts](https://github.com/raistlinsha-plus/inkstone/releases)

RAG reports document recall, evidence availability, citation/answer review and chart semantics separately. The synthetic cases are authored by the same development agent and are not independent user research. A high recall or rerank score does not establish answer correctness. Keyword evidence remains conservative for paraphrases. Vector-only is an evaluation baseline rather than a user-facing mode; it cannot bypass the BM25 evidence policy. API compatibility and provider billing vary. Missing usage/cost data stays unknown.

The app validates constrained chart data and source identity/hash. Answer checks flag selected numeric, date, unit and negation issues; any other claim still needs source review. An insufficient context budget can skip an oversized source intact to avoid sending a clipped table or negative condition.

The document sidebar supports one space or one document. Standalone chat can select one managed space and up to five documents from it, plus up to five local text attachments per turn. An attachment is a UTF-8 TXT, Markdown, JSON or MMD file up to 2 MiB. A conversation retains up to 12 attachment copies, and the assistant database caps attachment text at 32 MiB across conversations. Long files and entire spaces may only be represented by selected passages. PDF/DOCX/OCR, images as chat input, background bidirectional sync, multi-user collaboration and cross-space document moves remain future scope.

Wiki compilation is limited to ready documents explicitly authorized in one managed space, with per-batch and daily call limits. Changed source versions can invalidate Wiki summaries or references. Old generated Wiki pages without input provenance need to be rebuilt during the candidate upgrade. Automatic web search needs a separate Brave Search key and reads a bounded number of directly accessible public HTTPS pages. Search abstracts are used for discovery, while citations require retrieved page text. Dynamic or authenticated sites, redirects and unsupported formats may be skipped. Live Brave account verification is pending. [Wiki and web scope](DELIVERY-v0.7.2.md)

The companion has growth, CG albums and stories. The companion workspace supports season reading and a CG album. Motuan has an opt-in in-app pet with local motion and controls. The human characters use static artwork. Final artwork sign-off and natural multi-day use remain pending. Experience cards are not paginated, and timezone changes after a nonempty experience ledger are not supported.
