# Known preview limitations

The local development candidate is v0.7.0-rc.5. Published artifacts are listed in [Releases](https://github.com/raistlinsha-plus/inkstone/releases). The acceptance target is macOS 13+ on Apple Silicon. Developer ID signing, notarization and cross-machine installation are pending. Native Pinyin candidate confirmation, VoiceOver reading and long-running performance checks are pending. The isolated app passed five process-start/WebView bootstrap probes, and browser layout checks use synthetic IPC. See the [current delivery record](DELIVERY-v0.7-rc5.md).

RAG reports document recall, evidence availability, citation/answer review and chart semantics separately. The synthetic cases are authored by the same development agent and are not independent user research. A high recall or rerank score does not establish answer correctness. Keyword evidence remains conservative for paraphrases. Vector-only is an evaluation baseline rather than a user-facing mode; it cannot bypass the BM25 evidence policy. API compatibility and provider billing vary. Missing usage/cost data stays unknown.

The app validates constrained chart data and source identity/hash, but does not prove every generated category/period/unit pairing. Confirm results against original sources. An insufficient context budget now skips an oversized source intact rather than sending a clipped table or negative condition.

The v0.7 candidate implements companions, growth, CG albums and stories with static candidate art. Final animation/artwork sign-off and natural multi-day use remain pending. Conversation scope supports the whole space or one document, not arbitrary document sets. Experience cards are not paginated, and timezone changes after a nonempty experience ledger are not supported. Document formats remain plain text/Markdown and their structured fences; PDF/DOCX/OCR, background bidirectional sync, multi-user collaboration and cross-space document moves are not shipped.

Earlier retrieval evaluations are documented in the [v0.6.6 results](../evals/v0.6.6/RESULTS.md). Seventeen acquired packages still lack standalone local license text. See the [current delivery record](DELIVERY-v0.7-rc5.md) for the remaining distribution checks.
