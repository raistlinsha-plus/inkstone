# Inkstone v0.8.7 · Wiki 增量审阅与回答来源追溯

## Wiki 增量审阅

1. 在「知识 Wiki」打开待审阅提案。
2. 查看「改动对照」。对照以提案建立时的页面版本为基线，显示文档来源的新增、更新和移除，也会分别提示摘要和大纲的变化。
3. 核对来源原文后，选择发布或拒绝。有剩余提案时，可选择「审阅下一项」。发布时会再次核验来源。

## 保存后的来源追溯

在「AI 问答」选择「保存为文档」。受管理文档的引用会保留来源文档身份、原始行范围和内容版本。「回答来源」还会保留生成时的简短摘录。在分栏预览直接点击来源，或在正文编辑器按住 ⌘ 或 Ctrl 点击。

链接会按当前本机资料核验原文版本。原文变化或来源不可用时，界面会提示无法验证该引用。网上来源仍可通过其公开链接查看。受管理文档的引用依赖可以访问相应文档的 Inkstone 文档库。

## 本机升级与发行

本机应用沿用升级预检、资料快照、便携备份、原位替换和回退流程。GitHub 发布提供源码和校验文件，公开安装包的签名和公证面向后续版本。
