# Inkstone v0.7.2 source preview

**在受管理空间建立可核对原文的 Wiki，让有时效需求的问题按需查公开网页。**

- 在当前空间明确勾选可用文档后按主题整理。可浏览页面和原文位置，审阅或拒绝改动，符合核验条件时恢复旧版。自动维护只处理已授权资料，重要改写待审阅。
- BM25、可选向量和 Wiki 原文召回可共同取证。可选重排调整本地候选顺序，引用仍需满足原文规则。
- 「自动联网」默认关闭。配置自己的 Brave Search API 密钥并授权后，聊天模型仅根据当前问题判断是否联网。Brave 接收通过规则校验的公开查询。回答使用能直接读取的公开 HTTPS 正文，网页历史保留出处元数据。

**开始试用。** macOS 13+ Apple Silicon，中文界面。从本版本标签执行 `npm ci --registry=https://registry.npmjs.org` 和 `npm run desktop`。配置自己的兼容聊天 API，在受管理空间导入虚构文档，选择「知识 Wiki → 范围与维护」，先走一遍「整理 → 审阅 → 打开原文」。Wiki 整理会向已配置的模型发送获准资料片段。[v0.7.2 交付说明](https://github.com/raistlinsha-plus/inkstone/blob/v0.7.2/docs/DELIVERY-v0.7.2.md)

**交付边界。** 发布产物是源码预览。实际 Brave 帐号的端到端请求尚待验证，网页搜索仅覆盖能直接读取的公开 HTML 和纯文本。原生辅助功能、跨机安装和更大语料的检索评测另行验收。
