# Inkstone v1.2.0-beta.2 · 控件与编辑可靠性

macOS 本地构建 10212，基线为 beta.1 构建 10211。

## 可以直接试的操作

| 在哪里 | 怎么试 | 应看到什么 |
| --- | --- | --- |
| 文档 → 我的空间 | 搜索名称，清除搜索，再打开末行的「⋯」。用方向键选择「重命名」，输入中文或按 Esc。 | 旧名称在原行选中。输入法组词期间可以退选。退出菜单或取消改名后，焦点回到本行。 |
| 文档 → 文件夹 | 选中文件夹 A，打开导入再取消。把文件从 Finder 拖到窗口。 | 新窗口标出当前空间的根目录，列出笔记、独立图片、附件和跳过项。开启去重时，还可看到目标空间内已存在的数量。 |
| 文档 → 打开图片 | 添加同一张照片两次，或从同一空间的另一个文件夹再次添加。 | 再次添加时按原图内容查重，直接显示已有位置，省去重复的文字识别。点击「打开已有图片」可回到原图和已保存的描述。 |
| 空间首页 → 导出空间 | 导出含有独立照片的空间，解压 ZIP，再把解压后的文件夹导入空空间。 | 可打开预览、导出原图，读取原有 OCR 和已保存的说明。 |
| 任务或日历 → 任务详情 | 修改标题和执行时段，选择「保存并拆解」。 | 笔记写入成功后，问答草稿带入最新标题和排期，供你编辑和发送。写入失败时草稿留在详情中。 |
| 聊天 → 从回答创建任务 | 选择活动空间及笔记，确认要保存的原话。 | 可选目标为 Markdown 笔记。空间缺少可写笔记时可在确认时创建「任务清单」。 |

## 本机验证范围

- 「我的空间」在 960 × 640 的原生 WKWebView 窗口使用 24 个合成空间试验了搜索、末行菜单、浅深色、中文组词和焦点恢复。
- 在多段正文中间，使用 macOS 原生文本输入接口验证了组词、读取草稿、上屏和光标位置。用工具栏加粗这段文字，再切换源码、分栏和正文，文字仍显示为粗体。任务页面通过可控的写入失败验证了保留草稿和重试。第三方输入法兼容性和人工 VoiceOver 操作列入 rc.1 验收。
- 在隔离的 Inkstone 桌面窗口，通过系统保存面板导出空间，将 ZIP 解压后导入新空间。HEIC、HEIF、JPEG、PNG 四份原件与来源逐字节一致，预览与识别文字均可读取。原生后端测试另行核对了手动保存的图片说明与文档引用。HEIC 和 HEIF 两个扩展名使用同一份原生编码样本。

空间主界面、图片查看器和两类独立脑图的改版排在 beta.3。[前端体验版本计划](design/v1.2-frontend-roadmap.zh-CN.md)
