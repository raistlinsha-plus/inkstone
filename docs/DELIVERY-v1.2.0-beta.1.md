GitHub 源码预发布对应 macOS 本地构建 **10207**。这版汇集了从聊天创建任务、Markdown 与周历联动、双语界面及回答上下文说明。读者可以从标签自行构建并试用。

## 这一版可以试什么

- 在「任务」连续输入几件要做的事。打开其中一项，分别设置截止日和执行时段，再到「日历」调整时间，到所属笔记核对同一行清单。
- 在回答下点「更多回答操作（…）」查看本轮上下文，或将原话转为任务。输入框可直接选择资料及本轮网页搜索权限。
- 在文档里阅读长 Mermaid 图、脑图和数据图表。悬停或用 Tab 聚焦时显示操作工具。数据图表支持切换图、表与源码并导出 SVG 或 PNG。Wiki 资料列表支持按筛选结果批量选择，便于只授权所需笔记。
- 在「模型与设置」切换简体中文或 English。回答语言可单独指定，既有笔记、引文和任务标题保留原文。问答、向量、重排及 Brave 密钥保存在当前用户的 Inkstone 配置中，可在各服务设置里逐项导入旧钥匙串凭据。[密钥、语言与使用方法](USER-MANUAL.zh-CN.md)

## 2026-11-23 · macOS 构建 10203

左侧「任务」默认打开今天的清单，「日历」直接进入周历。悬停图标或用 Tab 聚焦可看到名称。在当前空间添加任务，首次确认会生成《任务清单.md》，也可指定已有笔记。正文中勾选任务后，清单和周历同步显示完成。拖动周历里的执行时段可以改期，截止日独立保留。

内置空间现名为「我的文档」。迁移沿用原空间标识，保留自定义空间名。

本轮通过 412 项前端测试和 340 项 Rust 测试。隔离的 macOS 原生窗口验证了新建任务、从周历返回文档、在正文勾选并重开核对。浏览器另外验证了从聊天原话建任务、截止与执行时段分别显示、深浅色和中英文导航提示。

## 从一句承诺到可跟进的工作

在提问或回答下选取“周五前发手册初稿”，核对原话并选定笔记。保存后在「任务」里可以勾选、设置截止日、安排执行时段或记录等回复。点击来源文档名可回到 Markdown 原行。在任务详情点「请 AI 帮我拆解」会生成一条可编辑的草稿。

任务标题与排期跟随文档。聊天原话的私有定位保存在本机会话库，导出单篇 Markdown 只带走用户确认的任务。重复确认同一段话会复用任务 ID。文档版本变化、有恢复草稿或出现重复 ID 时，先由用户处理受影响的文档。删除会话可清掉原话关联，笔记里的任务继续保留。

## 界面、模型与页边同伴

主要工作区和同伴第一季可即时切换简中和英文。回答语言可以随提问、按空间或全局设置。用户的标题、引文和既有文档保留原文。其他语言暂未随包提供，一些旧记录、底层错误和系统对话框沿用原语言。跨语言检索质量仍需独立评测。

回答下的「本轮上下文」区分实际服务请求、最终请求中的资料、随回答保留的资料及最终引用。请求失败或重试也会计入，服务返回 token 用量时显示实测值。页边同伴的动作解释取自本机事件；回顾来自用户确认的手札。旧会话没有逐次请求记录时会显示未知。

集成检查覆盖 66 个前端测试文件、398 项测试，Rust 库 325 项和 CLI 集成 1 项。18 项按需运行的外部服务或基准测试单独记账。TypeScript、生产构建、离线 worker、原型校验及文档链接均通过。

- 在独立标识的 macOS 候选窗口新增一项「等回复」任务，保存至隔离笔记，从清单点击文档名后，正文编辑器显示新任务并取得焦点。另做五次隔离启动，五次均完成 WebView 与原生层通信。
- 通过完整前端和合成 IPC，从提问选取原话、改标题和日期、选目标文档、保存并在空间任务清单核对。通过设置切成英文、缩窄窗口、更换浅色外观后，中文任务原话保留。
- 对 RC.4 结构的合成会话先做只读备份校验，再迁移到新结构。保留原问题及回答，旧回答的请求详情显示为未知。受控本机 HTTP 服务另行验证了提取时只发送已选择的消息，原始回答以外的草稿、其他回答和历史未进入请求。
- Apple M1、1,000 篇短笔记、5,000 个任务，热刷新中位 101 ms、P95 109 ms；切换一项完成状态并保存中位 24 ms、P95 27 ms。首开一次 191 ms。计时覆盖对应代码路径，窗口绘制和应用启动单独测量。可用[原生基准](../src-tauri/src/calendar_task_benchmark.rs)和[列表基准](../evals/v1.2/task-filter.mjs)复测。

## 问答质量和放行条件

使用 RC.4 冻结题包和原评分规则，分别记录候选命中、原句准入和最后进入上下文的要点。离线结果用于定位原句丢失的阶段。检验最终答案需同题真实模型输出，并逐项核对结论和引用。[冻结评测说明](design/after-rc4.zh-CN.md)

冻结题包中有 40 个对照回合，包含 53 个可答要点。基于同一份标注和本地关键词路径，结果如下。

| 原句所在阶段 | RC.4 | 本候选 |
| --- | ---: | ---: |
| 进入检索前八项 | 50/53 | 50/53 |
| 通过原句筛选 | 21/53 | 23/53 |
| 进入最终回答上下文 | 15/53 | 21/53 |
| 其中，追问要点进入上下文 | 0/13 | 2/13 |
| 其中，部分有据题的要点进入上下文 | 3/13 | 4/13 |

在旧 40 题回归中，34 道有据题里取齐全部原文的题数从 22 增至 24，目标为 27。仍应优先处理追问和多项条件。冻结题包的 50 个回合（含 10 个前置回合）均未观察到越过设定的资料范围。[完整离线对照及复现指令](../evals/v1.0/rc5/README.md)

构建 10201 的真实模型评测在读取 macOS 钥匙串的问答凭据时等待超时。对应运行发出的 HTTP 请求为零。尚无本候选的真实问答分数或独立人工盲评结果。达到原定的正确回答、配对及安全边界目标，并完成试用后，再决定正式版。[RC.4 对照记录](DELIVERY-v1.0.0-rc.4.md)
