# Inkstone v0.9.6 · 页边的书房同伴

## 在文档旁陪读

在左侧打开「书房同伴」，选择墨团、砚舟或知微。点「显示桌宠」，返回文档工作区。拖动角色靠近左边或右边，松手即可停靠。用 Tab 聚焦到角色后，左右方向键可以换边，上下方向键可以调整高度。切换文档、收起后重新显示或重开应用，桌宠会沿用停靠边和相对高度。编辑区较窄时自动收成书签，给文字和滚动条留出位置。

墨团抱着书签，砚舟使用铜书签，知微佩着叶形纸夹。点角色可以摸摸墨团或向人型同伴打招呼。「专注」、应用的「减少动态」和 macOS 减少动态都可以停播动效。文档问答开始时角色陪读，本次回答完整就绪时短暂抬头。打开旧回答、停止、失败或证据不足不会触发就绪动作。回答与引用仍在问答面板中。

## 写完后记一笔

1. 开启陪伴后，在受管理的空间中修改并成功保存文档。
2. 点页边角色，再点「记录本次完成」。核对或编辑卡片文字，也可以选择经历类型。
3. 勾选同意并点「确认并记录」。这条经历会出现在「书房同伴」的经历页。从正文或源码打开卡片，取消或确认后可以在原选区继续写。
4. 文档尚未保存、当天已经记过该文档，或保存凭据已过期时，按卡片内的提示处理。普通保存和打招呼均不会自动记入经历。每天最多两条，同一文档当天一次。

## 成长与第一季

「成长」显示初遇、相识、同行，以及下一章还需要多少条经历、多少个有效日或一次复盘。读完和明确跳过会分别记下。旧存档中无法区分的章节显示「已解锁」，可重新读完；已解锁形象和相册继续可用。阶段信物会随选用的形象出现在页边。「故事」支持续读，「相册」可回看已经解锁的 CG。全程使用本地资源。
