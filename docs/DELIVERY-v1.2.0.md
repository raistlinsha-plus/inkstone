# v1.2.0 · 本机稳定版本线

构建 10220 在 rc.1 基础上补齐简短的星期追问。例如前一轮询问阅览室周一的开放时间，下一轮问「那，周三？」时，可沿用已确认的对象，并在本轮资料里重新核对星期和时间。来源含混时继续请求澄清。

本机升级的备份验证增加一次完整恢复演练。在新建的私有临时目录中恢复便携备份，核对清单指纹、文档 ID、空间、路径与状态，退出演练时清理临时目录。

这是本机开发版本。正式对外放行仍需候选试用、独立回答与引用盲评、其他 Mac 的输入法与 VoiceOver 验收。公开安装包另需 Developer ID 签名、公证及干净 Mac 安装验证。[验收安排](ROADMAP.zh-CN.md)

本机复测还遇到 Apple Vision 精确识别服务载入失败。现在硬件和 CPU 的精确识别均报错时，会用系统快速识别器重试其支持的文字。不同系统版本的快速识别语种有差异。
