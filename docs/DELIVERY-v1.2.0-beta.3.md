# Inkstone v1.2.0-beta.3 · 空间、图片与脑图

**简体中文** · [English](DELIVERY-v1.2.0-beta.3.en.md) · [从源码构建](QUICKSTART.md)

此源码预发布版对应 macOS 构建 **10218**。在同一项目空间里，可以整理文件夹、翻看 iPhone 照片、检索图中文字，也可以直接在脑图上写下想法。

**试试这张图。** 导入社区阅读之夜的示例，双击节点改名，拖到空白处摆放。将分支放到另一个节点中央可改变它的上级。主题和手动位置随文件保存，选择「自动布局」可重新排版。[示例脑图](assets/v1.2.0-beta.3/zh-CN/reading-night.mmd) · [查看实际画布](assets/v1.2.0-beta.3/zh-CN/mind-map.png)

切换「文档」「任务」和「日历」时，左侧入口保持原位。在脑图上，右键点击节点可添加、改名或调整同级顺序。点击折叠按钮可暂时收起分支。

| 操作 | 在本版中如何完成 |
| --- | --- |
| 从空间找文件 | 进入「文档 → 我的空间」。打开一个空间，点文件夹看其中的直接子项。面包屑可回上级；在目录内新建或导入时，可核对目标位置。归档空间可查看资料，恢复后可继续写入。 |
| 看图与读图 | 打开 HEIC、HEIF、JPEG 或 PNG 等图片。空间中有多张图时按名称翻页。「查看文字」打开本机 OCR 和已保存的描述。「问图片文字」用这些文字做资料问答。 |
| 向视觉模型提问 | 点「分析图片」，核对预览、模型和问题，然后点「发送图片」。切到其他图后可回到原图接着看结果。点「保存描述并用于检索」后，这段文字写入图片资料，可用关键词找到并回到原图。 |
| 编辑 Mermaid 脑图 | 打开以 `mindmap` 定义的 `.mmd` 文件，双击节点改名。拖到目标中央可移为子节点，拖到上缘或下缘可调整顺序。复杂 Mermaid 语法使用原生预览，可在源码或分栏里修改。 |
| 写独立 Markdown 脑图 | 打开 `.mindmap.md`，双击改名、按 Tab 加子节点、按 Enter 加同级。可拖动整条分支。两种独立脑图都能选择「青竹」「彩色分支」「墨线」并随文件保存。普通笔记从「大纲脑图」查看正文结构。 |
| 把对话变成行动 | 从回答选取原话并写成笔记里的任务，在任务详情安排时间，到日历查看，再打开原文勾选完成。问答联网开关直接显示当前状态；日历的刷新、导出归入「日历操作」。 |

Wiki 在长资料列表中保留已选数及保存入口，筛选后可对匹配资料批量选择。索引和 Wiki 显示图片的原始名称。

## 验证范围

构建 10218 的 483 项前端测试通过。在 macOS 原生 WKWebView 中核对了 16 种导航状态，图标最大位移为 0 像素。另已用真实鼠标事件核对样式选择、节点拖动和重开文件。

图片切换、主动发送、保存和重试的交互验证使用合成图片和可控的模型回答。HEIC/HEIF 解码、OCR、原件导出和已保存描述的关键词检索由本机后端测试覆盖。本轮未调用用户的付费视觉模型。跨设备输入法、人工 VoiceOver 与真实模型对照保留在 rc.1 验收。
