# Inkstone v0.7.0-rc.3 交付说明

2026-11-06。本次连续完成rc.2可靠性与rc.3体验工作包，最终本机版本为0.7.0-rc.3。rc.2保留独立代码里程碑，不重复打包；本轮未发布GitHub或创建正式标签。

## 改动

1. 问答草稿在导航/退出前独立刷写，失败保留当前上下文；生成与草稿串行更新，失败可重试。退出会停止生成并等待待写草稿。
2. 后端持久接收确认后才清空对应问题；确认事件丢失以最终回执兜底；接收前失败保留输入和草稿，晚到确认不覆盖后来输入。完成回执异常时重新核对后端版本再保存草稿。
3. 经历卡保存失败保留文字和表单；历史搜索由后端过滤，支持200条分页、归档和空间约束。明确文档名或固定单文档首问可正常进入检索，原有证据门控保留。
4. 窄窗知识任务采用文档列表＋问答/检索两栏；返回编辑恢复文档区，不回写手动侧栏偏好。标题栏显示真实版本。
5. 简单脑图/Mermaid使用有界紧凑画布，可展开；保留缩放/导出保护。JSON表单左对齐，错误区和输入框留白统一；官方日历样例修复并加入格式契约回归。
6. 停止时非空部分回答在来源身份/hash核对后保存为stopped/cancelled，明确标记未完成；旧stopped无响应记录兼容。Markdown支持当前分支/选中回答与全部记录两种范围，JSON始终保存完整结构。

## 验证与本机更新

默认全量检查、针对性回归、隔离浏览器与隔离WebView冷启动分别记录。真实模型、本机原生输入法、系统授权、VoiceOver与实际视觉交互没有由无头浏览器代替；最终汇总见[审查与正式版判断](REVIEW-v0.7-rc3.md)。

本机更新的主入口为`/Applications/Inkstone.app`；旧工作目录中的启动入口指向同一安装版，防止误开v0.6.6。实际复制/签名/版本/hash与启动结果以本机私有安装回执为准。安装前使用产品备份函数创建完整包，检查valid=true及issues为空；原包和备份均留在忽略的artifacts目录。

没有新增第三方依赖。assistant/companion维持schema1、catalog/index维持schema3、备份format2；备份语义检查新增合法的stopped/cancelled部分响应支持。旧程序对新部分响应的恢复校验未承诺兼容，不建议直接使用旧版继续修改新会话库。

## 边界

正常退出等待草稿落盘；生成期间新草稿在本轮结束或退出前保存，强制结束进程仍可能丢失尚未保存内容。称呼尚未用于台词；美术仍为静态候选资源。任意文档集合、云同步、更多格式和新角色不在本次范围。

本轮结论为可以进入v0.7.0正式版收口开发；达到原生、自然多日试用、资源及发行门槛后再决定正式发布。

导出保护：未完成或含待核对图表的候选在Markdown中保留为明确标记的源码围栏，避免重新绘制被拒绝的图表或让未闭合围栏吞掉后续问题；JSON保留原始响应。

退出补充复核：单文档范围下尚未发送的问题，在正常退出时继续按最新固定范围保存；已通过修复前失败复现和修复后回归。
