# Inkstone v0.8.0 · 发布收口

此版本建立在 [rc.1](DELIVERY-v0.8.0-rc1.md) 与 [rc.2](DELIVERY-v0.8.0-rc2.md) 的问答取证、Wiki 审阅与本机可靠性改动上。证据不足时，独立问答引导用户补充所选资料或检查索引。网页禁用提示明确指的是公开网页搜索，聊天模型仍使用用户配置的服务。

## 本机验证

- 全量门禁 9 项通过。前端 304 项通过，Rust 235 项通过、7 项显式评测忽略。冻结开发集复测维持 49/52 完整入证，12 道缺少目标事实的题无误入证。
- 合成浏览器验证了无资料翻译、显式禁止网页搜索、历史回答重试、草稿保留，以及指定资料后的缺证提示。隔离 macOS 包通过 5 次冷启动和 WebView 启动调用。生产本机包通过临时签名完整性检查。
- 真实聊天模型与 Brave 连接探测在收到 HTTP 响应前超时。真实 Wiki 生成、独立答案评审、可见的原生交互和跨机安装仍待验证。

## 本机与公开发行

- 从 v0.7.8 升级前，用旧版备份。升级保留原始文档、Wiki 授权与设置。旧 schema 的生成页、修订和待审稿需重新整理。回退时使用旧应用与升级前备份配对。
- 公共源码发布需要正式提交的 CI 与答题质量门槛。macOS 安装包还需完成分发声明、Developer ID 签名、公证、Gatekeeper 和另一台干净 Mac 的安装验证。
- 真实聊天模型、Wiki 生成及 Brave 路径使用合成资料核验。正式评测把证据覆盖、答案断言、引用与拒答逐项记录，并保留失败结果。
- rc.2 的冻结开发集基线为完整入证 49/52，缺少目标事实的 12 道题无误入证。证据选择成绩与生成答案评审分开记录。[评测口径](../evals/v0.8.0/README.md)
