# v1.3.0 · 在通用对话里用图

在通用问答输入框旁点「添加图片」，从当前空间挑一张图。选「图中文字（OCR）」或「已保存的描述」时，只将所选文字作为图片资料。选「图片预览」时，发送前还能核对画面、服务地址和模型，或取消并移除图片。也可在同一轮选择一份笔记，对照提问后点击引用回到相应资料。

视觉服务接收从图片生成的 JPEG 预览。图片保存在本机，可以用 iPhone HEIC 原件导入后再选取。已删除的资料和与确认时不同的预览需要重新选择。切换图片、按 Esc 或取消确认均可在发送前返回。

合成资料测试涵盖 OCR、描述、图片与笔记的联合提问、服务端收到的内容、引用回源和取消发送。真实供应商支持的模型、计费和回答质量需分别验证。
