# Inkstone v1.0.0-rc.4 · 换个说法问笔记

Apple Silicon Mac，macOS 13 及以上，构建号 10004。

## 在一篇文档里试用

1. 打开自己的笔记，点「问这篇文档」。先问一件笔记确实记录的事，换个日常说法再问一次，打开引用核对原句。
2. 在同一轮追问两个事实，例如「周六借阅室几点关，讲座几点开始？」。如果笔记只写了关门时间，检查回答是否保留该时间及出处，并指出讲座所缺的时刻。如果笔记明确写了「另行通知」，可以引用通知原句。
3. 只想继续核对其中一个对象时，可以问「那借阅室周日呢？」。切换文档或遇到相似名称时，核对出处属于当前选择的文档、日期与对象。
4. 需要模型帮助理解不同措辞时，打开「模型与设置 → 问答模型 → 用问答模型核对候选原文」。此项默认关闭。开启后，每轮最多一次辅助核对，最多 8 段、合计 4,000 个原文字符。译写、公开网页搜索和空间授权均有自己的入口。

## 验证方式

在开发前冻结文档、问题和逐项评分依据。针对同一问题分别准备信息齐全和缺少一项信息的两份资料，按两种情形都正确来计算整对通过率。另回放 RC.3 使用过的独立 52 题与旧回归集，分别报告找到原句、实际回答、引用支持、错误拒答、服务失败与越界。已验证在辅助核对期间改名、移出范围、正文更新或取消时会撤回相关结果。设置页使用合成资料在离屏 WebKit 中验证了默认状态、键盘切换、保存和重开。开放场景的答案质量仍需人工核对。[上个候选版结果](DELIVERY-v1.0.0-rc.3.md) · [1.0 放行条件](design/v1.0.zh-CN.md)

## 最终候选的实测结果

2026-11-22，候选源码 `1e02f00`。真实模型为 gpt-4.1-mini。两版都在合成空间中使用关键词检索，开启候选原文核对，关闭公开网页搜索。每份题卷包含 20 对测试，共 40 个目标轮次，另有 10 个铺垫轮次。每一对保持问题相同，改变笔记是否提供完整答案。独立 AI 在隐去版本后核对两版全部 100 份答卷的内容和紧邻引用。下表只计 40 个目标轮次。

| 指标 | RC.3 | RC.4 |
| --- | ---: | ---: |
| 整题答对、缺项处理妥当且断言均有引用 | 15/40 | 15/40 |
| 同一问题的两份资料均通过 | 4/20 对 | 5/20 对 |
| 完整资料 / 部分缺证 / 全部缺证分别严格通过 | 5/20 · 4/13 · 6/7 | 6/20 · 2/13 · 7/7 |
| 答对且有直接引用的可答要点 | 17/53 | 15/53 |
| 实际关键断言获邻近引用支持 | 23/26 | 19/25 |
| 对有据题整题误拒 | 21/33 | 22/33 |
| 至少一项严重错误 | 3/40 | 2/40 |

两版各有 50/53 个可答要点的直接原句进入前八个检索候选。RC.4 在追问中的 13 个可答要点上仍为 0 个答对且有引用。20 对问题中多通过了 1 对，但整题严格正确数持平；部分缺证题和带有效引用的可答点均有回退。单次真实模型运行也有采样波动。上述 50 轮 RC.4 共发出 25 次 HTTP 请求，RC.3 为 14 次。每轮端到端耗时的中位数约为 21/19 毫秒（RC.4/RC.3），两版都有大量在本机直接结束的缺证轮次。P95 分别为 3.79 秒和 2.59 秒。[配对方法与复现](../evals/v1.0/rc4/README.md)

在沿用的独立 52 题中，RC.4 严格通过 **6/52**，RC.3 为 **1/52**。分组后，38 道完全有据题仅通过 1 道，8 道部分缺证题通过 0 道，6 道全部缺证题通过 5 道。RC.4 在这套题中有 11/84 个内容与依据均正确的评分点，严重错误和越界均为 0。有一次辅助选句未完成，应用退回本机结果。本组与上表使用不同的评分协议和资料，成绩各自比较。

## 本机验收与发布判断

前端 373 项、Rust 库 309 项及独立 CLI 进程测试 1 项通过。18 项聚焦路由回归覆盖部分作答、普通原文的使用范围、严格重排、追问以及改名或撤回。隔离版在 5 次冷启动中均完成 WebView 通信。桌面使用 Apple Silicon 本机构建与临时签名；日常安装的备份与回退方式见[本机版本管理](LOCAL-INSTALLATION.md)。

**保留为 1.0 候选版。** 开放域换问法、多轮指代和部分缺证仍有漏答，当前结果低于正式版的正确率与引用门槛。下一轮应优先解决前八个候选中有正确原文、最后却未形成回答的案例，再做独立人工盲评。

本机已从 v0.9.6 原位升级并通过启动、版本、程序签名和备份指纹复核。日常入口仍为 `/Applications/Inkstone.app`。模型辅助选句在迁移后默认关闭。
