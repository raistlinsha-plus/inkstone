# Inkstone 操作手册 · v1.0.0-rc.2

在 Mac 上打开 Inkstone 后，可以从一篇笔记开始，提问、核对原文，再回到写到一半的位置。这份手册使用中文版界面里的按钮名称。首次从 GitHub 安装，请先看[从源码运行](QUICKSTART.md)。

## 第一次打开

点左侧「文档」，在空间首页找到「从资料到第一条回答」。选择「用示例体验」，进入独立的样例空间。搜索“阅读活动”，打开一条结果，核对命中的原句。找到「离线问答练习」并点「体验模拟问答」，选择一道题，打开出处，再保存示例回答。这个练习使用预设内容，可以先跳过模型设置。

换回自己的空间，点「导入文档」开始日常使用。有资料的空间会收起入门提示，需要时点标题就能再次展开。

在文档列表中打开一篇文档的「…」后，也可以直接点击另一篇文档。按 Esc 会关闭菜单并回到触发按钮。用拼音输入时，先完成当前选字。

## 收集和整理资料

1. 在「文档」的空间选择器旁点「新建空间」，例如取名“社区阅读计划”。同一空间可以收集来自不同文件夹的资料。
2. 点「导入文档」，确认「导入到空间」，选择文件或文件夹，点「复制导入」。支持 Markdown、TXT、JSON、MMD，单篇文本最多 2 MB。勾选「一并复制源目录范围内的相对图片」可以带入符合条件的图片，单张最多 8 MB。
3. 在导入结果打开副本。之后的编辑保存在空间中，电脑上的原文件仍在原位置。「跳过相同内容」能避免重复副本，结果中可直接打开已有文档。一次选取多份文件、只有部分导入失败时，点「重试失败文件」。按文件夹导入时使用「重新检查并导入」，这样可以保留相对图片的位置关系。
4. 要跟进原文件的变化，打开文档行的「… → 检查来源更新」，核对后再应用。常用文档可以置顶。误删时到「回收站」点「恢复」。永久删除在回收站的文档操作中，确认前请先核对文档名。

## 编辑、插入内容和安排日程

打开 Markdown 文档，用「正文」写作，用「源码」查看原始 Markdown，用「分栏」对照。把光标移到目标段落，点「插入」，或在新段落开头输入 `/`，再选「JSON 数据」「脑图」「Mermaid 图表」「数据图表」「日程」或「日历」。例如整理一次活动时，可以在正文里插入脑图梳理分工，再插入日程记录日期。需要记录定量结果时，用「数据图表」编辑分类、系列和数值。核对数据表、单位和预览后再导出。

修改内容块后，先在块内完成或应用编辑，再保存文档。格式有错时，切到块的源码修正，预览恢复后继续写。「大纲脑图」可按整篇文档的标题查看结构。左侧「日历」汇总当前空间文档中的日程。修改前核对所属文档，新增时查看「新增事项保存到」。修改会写回文档，也可以导出 ICS 给其他日历使用。

## 搜索资料，或请模型回答

| 想完成的事 | 从哪里开始 | 核对结果 |
| --- | --- | --- |
| 定位某个词或名字 | 打开「搜索」，选好资料范围和关键词检索 | 点结果查看原文，关键词检索可以在本机完成 |
| 就一篇笔记提问 | 在正文或源码中点「问这篇文档」 | 打开回答的「本轮依据」和来源，对照实际原句 |
| 比较两份资料 | 左侧「AI 问答 → 添加资料」，从同一空间勾选文档，或附加临时文本文件 | 发送前核对资料标签。不同结论分别打开各自的引用 |
| 翻译或改写一段文字 | 左侧「AI 问答」新建会话，直接粘贴要处理的文本 | 本轮可按需添加资料。输入框的「本轮不搜索网页」可用于限定公开网页搜索 |

**第一次连接模型。** 在需要发送真实问题时点「连接问答模型」，或进入「模型与设置 → 问答模型」。填入兼容服务地址、模型名称和服务所需密钥，测试后保存。返回待发送的问题，检查资料范围，再按 Enter 发送。Shift+Enter 换行。中文输入法选词时的回车用于确认候选。远程服务使用 HTTPS，本机回环地址可用 HTTP。密钥由 macOS 钥匙串管理。

**按小问核对原文（1.0 候选版）。** 打开文档后点「问这篇文档」。例如，问“借阅室周末几点关闭？讲座何时开始？”，点回答旁的来源核对每一项。根据本次找到的资料，回答可以只给出关门时间，并提示讲座还缺哪一项信息。

在 RC.4 中，可以接着问「那周日呢？」。如果上一轮只有一个明确对象，应用会查找周日的原句；上一轮同时询问过多个不同对象时，可以直接写出想继续核对的对象。如果笔记只回答了部分问题，回答会列出已找到的原句、引用编号和仍待核实的小问。点引用编号可以回到原文。若看到「相关原文，逐项核实不足」，表示常规检索找到了相关段落，可以点开来源，核对其中是否写明所问的对象、条件和数值。原文写明「另行通知」的事项，可以点来源查看这句说明。

资料经常使用不同说法时，可进入「模型与设置 → 问答模型」，勾选「用问答模型核对候选原文」并保存。此项默认关闭。本机筛选后仍有待核对的小问时，开启此项会把小问、必要的标题和原句发给当前问答模型，范围限于所选资料，每次最多 8 段、合计 4,000 个原文字符，每轮最多增加一次请求。使用远程地址时，服务商会收到这些片段。「本轮不搜索网页」控制的是公开网页搜索，远程模型的原文核对有独立开关。更换问答服务地址后，需重新选择是否启用。旧有有据问答、向量检索和重排各自的传输范围见下文。

**选择模型会收到的内容。** 用向量检索前，在「模型与设置」配置向量模型，并在「索引」为所选资料建立向量。向量化时向服务发送选定片段，向量查询时发送查询文本。可选重排需要单独的 Cohere 兼容重排接口，会收到问题和候选片段。有据问答会把问题、需要的上下文和用于回答的证据发送给问答模型。点「回答偏好」可管理随请求使用的表达偏好。

**需要公开网页时。** 在「模型与设置」的自动联网设置里配置 Brave Search API 密钥、授权并保存。测试连接使用固定的公开查询，可能计入额度。日常提问时，系统会根据问题和本轮许可判断是否搜索。查看回答标出的来源，确认它来自所选笔记还是公开网页。网页没有成功读取时，可根据提示核实公开信息。

**核对后接着写。** 问题涉及两份资料时，先看两份原文是否都被引用。若回答提示“本次提供的片段不足以核实”，可以打开来源补读上下文，或增加相关笔记后再问。只有原文明说某项未记录，才适合把这个结论写回笔记。遇到差值、合计等推算时，请逐项核对原始数值、单位和引用。在正文或源码选中一段、向文档提问、打开引用后，点「返回写作位置」回到原文和原选区。点「保存为文档」可将回答留作可编辑笔记，点「继续编辑原文」回到之前的文档。原文发生变化时，按引用的版本提示核对现行原文。[两份笔记的练习](../examples/v0.7.3/README.md)

## 让本机其他工具查资料

在候选版的「模型与设置 → 外部工具」给每个工具选择一个空间并创建只读连接。工具可以用 `inkstone-cli` 搜索已有的本地关键词索引、核对引文，再用自己的模型写作。凭据与模型密钥分别管理，可随时撤销。[CLI 构建、配对与引用示例](EXTERNAL-TOOLS.zh-CN.md)

## 整理知识 Wiki

1. 打开需要整理的空间，进入「知识 Wiki → 范围与维护」。勾选「启用当前空间的 Wiki」，填写关注主题并选定来源文档。首次可选「发布前全部审阅」。
2. 点「保存范围与维护」，再点「整理所选资料」。整理时，获准资料中的文本会发送给配置的问答模型。
3. 打开「待审阅」，选择一项改动。对照上个版本，逐条点开来源，查看文档、行号和原句。只有一篇笔记提到的事项，应按该篇笔记理解。两份来源给出不同数值时，分别核对日期和适用条件。
4. 核对通过后点「发布改动」。证据不足时，按提案提供的操作选择「仅发布原文摘录」，或拒绝后重新整理。已发布主题可用于后续查找原文。旧摘录的行号对应当时版本，打开当前文档可核对变化。
5. 资料改稿后，在候选主题的审阅页对照「上版引用」和本次原句，并核对各自的行号。需要撤回文档时，先点「查看清除范围」，核对受影响的主题、已发布版本与待审数量，再点「确认保存并清除」。清除包括依赖所撤来源的相关历史。原始文档保留，可用剩余资料重新整理。

## 把书房同伴放到页边

1. 打开左侧「书房同伴」。初次使用点「认识同伴」，选择墨团、砚舟或知微并开启陪伴。在「桌宠」点「显示桌宠」，再打开一篇文档。
2. 将角色拖到左边或右边，松手停靠。也可以用 Tab 聚焦角色，左右方向键换边，上下方向键调整高度。重开后会沿用原位置。窄窗时角色收成书签。需要完整的写作空间时可点角色并选「收起桌宠」。
3. 点墨团可以摸摸它，点砚舟或知微可以打招呼。在「温和陪伴」下，文档问答开始时同伴会陪读，本次回答完成时会短暂抬头。选「专注」、启用「减少动态效果」或启用 macOS 减少动态，角色会保持静止。
4. 在受管理的空间中修改并保存一篇文档，点页边角色的「记录本次完成」。预览或修改文字和经历类型，勾选同意并点「确认并记录」。取消或确认后可回到原选区。同一篇文档当天最多记一次，每天合计最多两条。只有确认后，卡片才会成为一条经历。
5. 去「成长」看下一阶段还需要的经历、有效日或复盘。去「故事」续读或跳过章节，已解锁的 CG 可在「相册」回看。旧档中无法区分读完和跳过的章节会显示「已解锁」。[页边陪读和成长](DELIVERY-v0.9.6.md)

## 导出、备份与恢复预演

分享当前空间时，从空间首页点「导出空间」。要备份全部空间，则打开「备份与恢复预演」。先应用或取消尚在编辑的内容块，再进行备份。

1. 点「选择父目录」，填新 ZIP 文件名，点「生成并校验备份」。完成后核对保存路径和文件数。便携备份覆盖各空间的正文、附件、目录、历史及恢复草稿。外部原件应单独保存，重新安装后按需重建索引、配置服务或授权钥匙串。
2. 检查已有文件时，点「选择备份包 → 校验清单与文件」。看到「备份校验通过」后，可以做恢复预演。
3. 点「选择恢复父目录」，填一个全新的文件夹名称，点「生成恢复预演副本」。打开生成目录核对内容。日常应用会继续使用原工作库。需要回退一次本机升级时，使用该次升级记录中的事务目录。[本机升级与回退](LOCAL-INSTALLATION.md)

## 遇到问题时

| 现象 | 先检查这里 |
| --- | --- |
| 搜索有结果，回答仍提示缺证 | 查看本轮资料标签和「本轮依据」。若选了混合检索，在空间首页点「查看逐文档索引」检查所选文档是否已准备好 |
| Wiki 没出现预期结论 | 核对关注主题和授权文档，再看「待审阅」及来源是否已变更。原文缺少依据的结论可以保留待核对 |
| 桌宠已显示但静止 | 检查同伴是否选择「温和陪伴」、应用和系统是否减少动态。窄窗书签可通过拉宽编辑区展开 |
| 记录经历的按钮暂不可用 | 查看卡片提示。确认当前文档已成功保存、保存凭据仍有效、当日尚有记录名额 |
