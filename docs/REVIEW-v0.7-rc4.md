## 代码与数据审查

删除已完成而列表刷新失败时保留“已删除”状态，只允许重新刷新，不重复删除。

排序从 LibraryBrowser 中抽到共享纯选择器和偏好边界；删除交互独立到 TrashDialog，后端生命周期独立成模块。App 仅增加来源可用性提示与范围文案，避免把文件清理塞进主编排组件。

删除接口只接收空间/文档 ID、后端 token 与 operationId，不接收删除路径。后端交叉核对专属目录、身份、当前状态、完整清单与预览有效期；逐层拒绝 symlink，准备动作先记日志再移动，同文件系统暂存与父目录刷盘。维护独占与备份/写入互斥，结果不确定时不显示成功。

已确认的问答快照与经历文本是历史用户数据，保留但不能替代新事实证据。清除未确认经历凭据/待处理意图，成长去重账本不倒扣；来源失效继续由后端现存身份/hash 检查约束。删除不等于 SQLite 旧页、系统备份或外部导出文件的取证级擦除。

catalog schema4 有升级前一致快照，完整备份接受旧 schema1–3 和新 schema4，索引 schema 不随 catalog 改动。默认自动测试使用合成资料、不读钥匙串、不调用付费 API。额外的本机备份操作器只在显式隔离测试 feature 下编译，并且只接受私有 artifacts 下的关闭应用快照。

## 本机与真实服务记录

本机安装前备份、签名与文件核对、隔离启动和浏览器回执分开保存。更新期间发现另一个 v0.6.2 历史入口被重新启动，同步器在写入前停止；该入口也纳入本轮更新，避免 Dock 再次打开旧版。真实服务采用用户已授权 API 和合成文本，密钥只在进程内使用，不写入仓库、报告或应用配置。真实服务共 5 次成功 HTTP 请求：text-embedding-3-small 返回 1536 维；qwen3-reranker-0.6b 将相关资料排首位；gpt-4.1-mini 两轮合成问答正确保留指代与引用，缺少预算一轮在本地拒答；另一次流式请求收到首段内容后由客户端关闭。小样本人工逐来源复核通过，不代表总体准确率。初次环境 TLS 失败（默认 CA 文件缺失，未发出 HTTP）及调用器报告名缺少后缀的本地拒绝均保留；改用公开 CA 包并保持证书验证、修正文件名后才完成验收。流式客户端关闭不等同于本机 UI 停止按钮验收。

实际 Mac 可见交互和读屏未由无头浏览器或 bootstrap 检查替代。当前会话没有可用的桌面控制工具，未宣称原生界面已验收。

## 已知限制与下一步

生成期间的新问题草稿仍排队到本轮结束或正常退出前保存，强退前未刷盘部分可能丢失。没有新增文件夹树、手动拖拽顺序、批量/清空回收站、自动过期删除、任意多文档会话范围或系统桌宠。

正式版优先完成集中原生验收和素材/自然使用签收。大语料检索质量、首次模型引导、包体与性能测量继续独立专题；不因本轮按钮修复而重新扩大格式或角色范围。
