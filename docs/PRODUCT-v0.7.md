# Inkstone v0.7 候选版产品说明

更新日期：2026-11-05。当前本地应用为 **0.7.0-rc.1**，最近公开源码预览仍为v0.6.6。
本文描述已接入应用的能力、使用路径与已知问题；独立离线原型不作为生产功能或验收证据。
交付制品、先前测试与限制见[候选交付说明](DELIVERY-v0.7.md)。

## 产品定位与适用范围

Inkstone把本地Markdown写作、文档空间、带引用的知识问答和可关闭的角色陪伴放在一个桌面工作台。
验证目标是macOS 13+ Apple Silicon；模型由用户自己的兼容API提供，不内置模型权重或托管文档服务。
默认组织单位是产品中的“文档空间”。一个空间可收集电脑不同位置的文件副本，拥有稳定身份。
本地目录是资料来源或高级直接编辑方式；它不自动等同于产品空间，也没有隐含双向同步。

## 文档与编辑

- 新建空间和文档，复制导入MD、TXT、JSON、MMD文件；默认编辑空间副本，外部原件保留。
- 查找标题、查看最近和置顶文档、按类型筛选、使用回收站及导出。
- 已导入文档可比较来源更新；双方都修改时阻止直接覆盖，可保留两份。
- 支持受保护的历史恢复、来源链接重新关联及恢复诊断。
- Markdown提供正文、源码、分栏和大纲脑图视图；富文本范围以Markdown可表达的内容为准。
- 正文支持标题、列表、任务、表格、引用及代码等格式，提供工具栏、插入菜单和空段斜杠入口。
- JSON、Mermaid、脑图、日程和受约束的ECharts数据图表可在正文内显示和编辑。
- 图表采用受约束数据格式，不执行任意脚本；普通Markdown阅读器可能只显示专用围栏的源码。
- 文档日程可聚合到空间日历，支持回写与ICS导出；重复规则、系统提醒和外部日历双向同步尚未提供。
- 保存、恢复草稿和外部修改冲突继续保护文档；问答草稿另有本轮发现的边界问题，见后文。

推荐路径：创建空间 → 复制导入 → 正文编辑与源码核对 → 保存 → 需要时显式比较来源更新。
“打开本地目录”属于高级直接编辑原件模式，进入前应明确这与复制导入的区别。

## 检索与会话式问答

- 检索包括本地BM25、BM25与向量的混合检索，以及可选独立重排序；结果显示实际方式及降级状态。
- 使用前明确选择资料建库；混合检索和重排依赖相应模型配置与当前索引准备情况。
- 当前会话固定在整个空间或单文档范围；任意多文档集合选择尚未实现。
- 支持持久多轮会话、未发送草稿、历史、重命名、归档、删除及Markdown/JSON导出。
- 修改既有问题可产生保留原内容的分支；同一问题可重新生成、保留并切换回答候选。
- 侧栏问答与展开阅读共享会话；生成时支持停止，并显示准备资料、生成或失败状态。
- 每个回答候选保存自己的内容和来源快照；旧候选的复制、保存或插入使用其自身来源身份。
- 回答可包含Markdown和通过校验的结构内容；可复制Markdown、另存文档或预览后插入当前正文。
- 来源预览显示本轮片段、行号和版本，打开原文时再核对当前内容。
- 追问可使用重新校验的前轮来源身份解析对象，当前属性仍须由本轮资料支持。
- 历史AI断言、角色剧情或经历卡不会使缺少资料的回答获得证据资格；资料不足时拒答或澄清。
- 这是保守的资料支撑检查，抽象改写、指代与跨文档问法仍可能漏答，不等于完整语义事实验证。

推荐路径：核对资料范围与索引 → 首问 → 阅读来源 → 追问 → 比较候选 → 显式保存或插入回答。
资料更新、问题变化或模型错误后，按界面提示重新核对；命中和高重排分不代表答案一定正确。

## 角色与成长

三类角色可由任何用户自由选择，工具和知识能力相同，不根据用户性别强制分配。

| 角色 | 形象与产品关联 |
| --- | --- |
| 墨团 | 非人型墨色书猫，以叶纹纸签关联纸张、笔记与安静陪读 |
| 砚舟 | 27岁成年男性，以铜书签关联书房与整理思路 |
| 知微 | 25岁成年女性，以叶形纸夹关联观察、表达与保留不同想法 |

陪伴默认关闭；启用时默认专注模式和减少动态，可收起、切换角色或关闭。
角色入口位于问答区域，展示真实问答的工作中、需确认、就绪或失败状态；当前不是系统桌面悬浮宠物。
固定剧情与轻互动离线可用，不增加单独的模型调用。温和陪伴使用预设表达，不等于开放式角色聊天。
当前共三阶段、九章故事、九张阶段形象和六张CG，素材为静态候选插画。

| 阶段 | 开章条件与解锁 |
| --- | --- |
| 初遇 | 启用角色后可读相遇短章；主动读完或明确跳过处理章节 |
| 相识 | 全局至少3条有效经历、2个不同有效日，且该角色初遇章已处理 |
| 同行 | 全局至少8条有效经历、5个不同有效日，有一次实际复盘，且该角色相识章已处理 |

成长条件跨空间累计；各角色保留自己的章节、选择和形象进度。不要求连续使用，也不按字数、问答次数或付费调用增长。
处理对应章节后开放阶段形象及相识/同行CG；同行章包含选择，重看不能覆盖已保存选择。
只关闭故事不等于读完；达到条件后主动开章，不强制中断写作。不使用离开惩罚或进度倒扣。

## 经历卡、偏好与数据控制

1. 在已开启陪伴的受管理空间中，实际修改并成功保存文档，后端才产生工作凭据。
2. 选择“本次完成”，检查拟存文字和类型，明确同意后确认记录；普通保存、阅读、提问或轻互动不计成长。
3. 新确认受保存凭据15分钟有效期约束；同文档同有效日仅计一次，每日全局最多两条。
4. “复盘”要求该文档已有经历，且本次实际保存内容与之前不同；勾选类型不能替代内容校验。
5. 失败时工作正文保留；已持久的待存经历可重试，仍核对角色、空间及原文，避免重复奖励。

外部直接编辑目录可使用陪伴，但不能记录受管理空间的工作经历。
经历卡可修改或删除文字；删除卡片文字仍保留不含该文字的去重账本，已解锁形象不会倒扣。
首次启用按本机时区确定有效日；已有经历后暂不支持修改日界时区，避免历史日期重分。
用户可确认回答组织、长度和展示单位偏好，并按允许范围编辑、停用或删除；偏好不覆盖证据和事实核对。
“称呼”字段目前可以存档，但尚未接入固定台词或问答称呼应用，不应理解为已生效的完整人格记忆。
同伴资料支持单独JSON导出及清空；清空不删除工作正文、知识会话、索引或API密钥。
经历卡暂未分页。关闭陪伴后不补记历史；当前实现也暂停把角色表达偏好加入问答。

## 本地资料、外发与备份

文档、目录、索引、会话、来源快照、草稿、经历和剧情进度保存在本机；密钥使用macOS Keychain。
关键词检索本身不调用模型。向量化发送选定片段；重排发送问题和候选摘要；问答发送问题及选定证据。
多轮生成还可能发送最多六条先前用户问题、合计最多4,000字符，以及当前范围启用的表达偏好。
故事和经历卡不作为事实检索资料，历史AI回答不被当作新事实依据；角色模块不额外调用模型。
格式2完整备份纳入会话和角色数据库，因此可能含私人问题、来源摘录、经历和偏好；不包含API密钥。
旧格式1仍可读取，明确提示缺少新域数据；恢复先在新目录预演，不直接覆盖当前资料库。
删除当前会话或同伴数据不会删除用户先前导出文件和旧备份。外发与处理边界见[安全说明](../SECURITY.md)。

## 本轮已复现的问题与建议处理顺序

以下均为未修复问题。定向测试证明了现有失败行为，不表示相应修复已验收。

| 优先级 | 已复现问题 | 用户影响与改进方向 |
| --- | --- | --- |
| 先修 | 干净正文状态下，问答输入后600ms内切空间会取消待写草稿 | 切回后刚输入的问题消失；在切换上下文前独立刷问答草稿，失败保留输入 |
| 先修 | 发送在后端接收前失败，前端已清空输入并取消待写草稿 | 快速发送的问题既无轮次也无草稿；收到持久接收确认后再清空，失败可重试原问题 |
| 先修 | 生成中输入下一问题，草稿使用旧会话版本写入 | 出现版本冲突且完成后警告残留；串行合并生成结果与待写草稿，成功后清除对应错误 |
| 先修 | 经历卡修改保存失败仍立即退出编辑 | 新文案丢失、无法原地重试；等待写入成功再退出，失败保留编辑框 |
| 随后 | 历史界面只筛选最近200条，未使用后台标题查询 | 更老会话存在却搜不到；接入后台查询、分页及结果范围说明 |
| 先修 | 单文档首问“这份青禾方案的报名人数是多少？”被当作无前文追问 | 即使选定青禾方案.md仍本地澄清；去掉“这份”可正常检索，应结合显式对象与单文档范围解析 |

最后一项由本轮真实Rust领域探针确认，是问句路由与资料利用问题，不是远程模型准确率结论。
次要待改进项包括固定范围会话的向量准备提示、会话标题长度一致性，以及停止后保留未完成回答的体验。

## 当前验收状态与版本边界

本轮默认自动回归、定向缺陷探针及界面检查分别记录；测试数量与结论以本轮审查报告为准。
本轮没有重新运行真实API评测；交付说明中的两次真实请求属于候选开发时的合成冒烟记录。
本轮尚无原生应用UI验收，不能宣称真实WebKit交互、中文候选、系统授权或VoiceOver已通过。
最终动画、严格像素网格与资源终稿签收、五个不同使用日自然成长试用仍待完成。
Developer ID签名、公证、跨机安装及其他平台验收未完成；当前使用本地临时签名。
PDF/DOCX/OCR、云同步、多人协作、跨空间移动、任意多文档问答选择及桌面悬浮宠物仍为后续范围。
