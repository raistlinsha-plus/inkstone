# 砚台 · 产品与功能总览

**简体中文** · [English](PRODUCT.en.md) · [操作手册](USER-MANUAL.zh-CN.md)

**v1.2.0-beta.3** 面向 macOS 13 及以上的 Apple Silicon Mac。砚台把 Markdown 笔记、资料问答和待办事项放在同一个空间。可以先离线写笔记、排任务或搜索原文，需要问答和整理 Wiki 时再接入自己的模型。

比如周一复盘时答应周五交手册，可以从聊天原话建立任务，选定存放任务的笔记，把截止日设在周五，再在周历里安排周三的写作时段。周三从日历打开任务便能回到笔记原行。界面支持简体中文和英文，问答的输出语言另行设置。[本版交付与验证](DELIVERY-v1.2.0-beta.3.md)

## 从两份笔记开始

假设你有一份活动计划和一份会后复盘，分别放在电脑的两个目录。把它们复制导入同一个「阅读项目」空间，先搜索“场次”并打开原段落。接上问答模型后，可以问“原计划办几场，实际办了几场？”。点回答的引用能核对哪项数字出自计划、哪项出自复盘。把回答另存成文档，再回到原来的选区接着写。项目资料增多后，可以选出需要长期维护的笔记，交给 Wiki 整理。[两份虚构笔记及示例问题](../examples/v0.7.3/README.md)

## 主要工作区

| 工作区 | 适合的任务 | 留下的结果 |
| --- | --- | --- |
| 文档空间 | 将笔记和独立图片导入选定文件夹，按标题查找资料或置顶常用文件。可在「我的空间」搜索和重命名空间 | 笔记保留本地副本。图片保留原件、预览与文字说明，随空间一同导出 |
| 独立脑图 | 双击节点改名。把分支拖到其他节点上可调整层级，拖到空白处可自由摆放 | 节点层级、配色和手动位置保存在同一份文本文件中。重开后可继续编辑，也可导出 SVG |
| 编辑器 | 用正文或源码写 Markdown，分栏核对。可插入 JSON、Mermaid、脑图、日程和数据图表 | 内容保存在笔记中。图表工具栏在悬停或聚焦时出现，可核对数据表，导出 SVG 或 PNG |
| 任务 | 从清单直接录入，在笔记中插入，或从对话里选取原话后确认 | 每个跟踪任务对应笔记里的一条 Markdown 清单项。标题、完成状态、截止日和排期同步显示。「保存并拆解」把已保存的标题和排期带入问答草稿 |
| 日历 | 在周历中查看执行时段、截止日和跟进提醒，拖动执行时段改期 | 调整保存回原文，点击来源可回到对应行。文档中的日程也可汇总并导出 ICS |
| 检索与文档问答 | 离线搜关键词，或为当前文档、空间提问并核对引用 | 显示来源片段和位置。必要时从保存的回答中查看当时摘录，另开当前原文 |
| 独立 AI 问答 | 翻译、改写、追问，按轮选一个空间中的资料或附加本地文本文件 | 保留会话和各轮依据，可把有用回答另存成 Markdown 文档 |
| 知识 Wiki | 选择一个空间内允许整理的资料，审阅主题、变化、分歧和依据 | 主题页连接到已核验原文。可以拒绝改动，或仅发布有依据的摘录 |
| 书房同伴 | 让角色在页边陪读，保存文档后决定是否记录这次完成的工作 | 在本机保存已确认的经历、成长进度、已读章节及解锁的插画 |

终端或其他 AI 工具也可通过单独授权的连接读取一个空间。CLI 返回有限长度的原文、版本与行号，适合把已有笔记接入其他工作流。[接入手册](EXTERNAL-TOOLS.zh-CN.md) · [beta.1 问答评测](DELIVERY-v1.2.0-beta.1.md)

### 怎样选检索、问答或 Wiki

- **记得原词，想找原文。** 从检索开始。BM25 在本地运行。配置嵌入服务并备好索引后可混合向量召回，也可单独配置重排。结果会说明当次实际使用的方式。
- **想解决眼前的问题。** 在编辑器点「问这篇文档」可以就地核对；想换话题，可直接去「AI 问答」。指定本地资料后，证据不足时会提示缺口。独立问答支持选同一空间的最多五篇文档，并可另附最多五个文本附件。已授权 Brave Search 的情况下，模型按问题决定是否查公开网页。[资料范围与附件限制](KNOWN-LIMITATIONS.md)
- **准备长期维护一个主题。** 在「知识 Wiki → 资料范围」筛选并勾选资料，可批量选择匹配项。整理后进入「审阅与变更」。两份文档记载不一致时，核对两端原句，再决定发布、退回或仅保留摘录。来源更新后，原有引用仍可用于查看历史摘录；跳往当前原文时需要重新核对。[Wiki 变更示例](DELIVERY-v0.9.4.md)

### 书房同伴如何成长

在左侧「书房同伴」任选墨团、砚舟或知微，点「显示桌宠」回到文档。小角色停在编辑器左侧或右侧，窄窗自动收成书签。文档问答开始时它会陪读，回答就绪时短暂抬头；专注或减少动态适合需要安静写作的时候。

保存文档后，可以从页边角色菜单预览「记录本次完成」，确认文字和类型再写入经历。同一文档一天最多记录一次，每天最多两条。成长页分别显示「初遇」「相识」「同行」的进度与下一步条件，可在「故事」续读或到「相册」重看 CG。同伴动作、经历与故事在本机运行，不产生独立的模型调用。[书房同伴操作说明](DELIVERY-v0.9.6.md)

## 本地存储与服务边界

文档空间是应用管理的一组副本，可以收集多个来源目录里的文档。常规导入保留原件，比较和采纳外部更新由用户发起。高级的「打开本地目录」会直接编辑所选目录里的文件。备份、恢复与升级前的资料保护见[本机安装、备份和回退](LOCAL-INSTALLATION.md)。

编辑、离线示例、关键词检索和同伴故事可以先于模型配置使用。生成真实回答、整理 Wiki、构建向量和调用重排时，相应的服务商会收到该任务所需的问题、正文片段或候选证据。启用网页搜索后会向 Brave 提交经过校验的公开查询。模型密钥保存在 Inkstone 的本地私有配置中，日常使用无需登录钥匙串授权。旧密钥可在设置中按服务导入。除 Markdown、TXT、JSON 和 MMD 外，可导入 HEIC、HEIF、JPEG、PNG、WebP 和 GIF。图片文字由 macOS 在本机识别，可用于检索与问答。需要描述画面时，可在图片页主动将预览发送给已配置的视觉模型，再保存描述。PDF 支持及其他规划见[路线图](ROADMAP.zh-CN.md)与[已知限制](KNOWN-LIMITATIONS.md)。[模型与隐私](../SECURITY.md)

GitHub 提供源码及校验和，本机可自行构建独立应用。首次试用请从[源码快速开始](QUICKSTART.md)进入；操作入口、日常使用步骤与故障处理见[用户手册](USER-MANUAL.zh-CN.md)。实现、验证与版本变化见 [4A 架构](ARCHITECTURE-4A.md)、[技术栈](TECH-STACK.md)和[变更日志](../CHANGELOG.md)。
