# Inkstone 砚台 · 产品与功能总览

本文涵盖 **v0.9.6** 与源码预发布版 **v1.0.0-rc.4**，面向 macOS 13 及以上的 Apple Silicon Mac。Inkstone 适合经常整理项目笔记、写作时需要回到出处的人。文档保存在本机，可以直接写 Markdown，也可以用自己的模型 API 从选定笔记中提问、整理 Wiki。

在 **1.2 集成候选**中，从聊天选出的承诺也可以回到笔记。比如周一复盘时答应周五交手册，可直接从原话建立任务，在周三安排写作时段，周四设为等回复。任务与日历均能打开对应文档行。主要工作区提供中英文界面，问答可展开当轮实际使用的上下文。[候选交付](DELIVERY-v1.2.0-beta.1.md) · [中英文入口](USER-MANUAL.en.md)

## 从两份笔记开始

假设你有一份活动计划和一份会后复盘，分别放在电脑的两个目录。把它们复制导入同一个「阅读项目」空间，先搜索“场次”并打开原段落。接上问答模型后，可以问“原计划办几场，实际办了几场？”。点回答的引用能核对哪项数字出自计划、哪项出自复盘。把回答另存成文档，再回到原来的选区接着写。项目资料增多后，可以选出需要长期维护的笔记，交给 Wiki 整理。[两份虚构笔记及示例问题](../examples/v0.7.3/README.md)

## 主要工作区

| 工作区 | 适合的任务 | 留下的结果 |
| --- | --- | --- |
| 文档空间 | 从多个目录复制导入，按标题或类型查找，置顶或导出资料，从回收站恢复误删文档 | 空间中有可编辑的本地副本，保留外部原件。之后可以比较来源变化 |
| 编辑器与日历 | 用正文或源码写 Markdown，分栏核对；在正文插入 JSON、Mermaid、脑图、日程或受约束的数据图表 | 内容仍保存在文档中。空间日历汇总文档里的事项，编辑后回写原文，也可导出 ICS |
| 检索与文档问答 | 离线搜关键词，或为当前文档、空间提问并核对引用 | 显示来源片段和位置。必要时从保存的回答中查看当时摘录，另开当前原文 |
| 独立 AI 问答 | 翻译、改写、追问，按轮选一个空间中的资料或附加本地文本文件 | 保留会话和各轮依据，可把有用回答另存成 Markdown 文档 |
| 知识 Wiki | 选择一个空间内允许整理的资料，审阅主题、变化、分歧和依据 | 主题页连接到已核验原文。可以拒绝改动，或仅发布有依据的摘录 |
| 书房同伴 | 让角色在页边陪读，保存文档后决定是否记录这次完成的工作 | 在本机保存已确认的经历、成长进度、已读章节及解锁的插画 |

在 1.0 候选版中，终端或其他 AI 工具也可通过单独授权的连接读取一个空间。CLI 返回有限长度的原文、版本与行号，适合把已有笔记接入其他工作流。[接入手册](EXTERNAL-TOOLS.zh-CN.md) · [RC.4 使用示例与问答质量](DELIVERY-v1.0.0-rc.4.md)

### 怎样选检索、问答或 Wiki

- **记得原词，想找原文。** 从检索开始。BM25 在本地运行。配置嵌入服务并备好索引后可混合向量召回，也可单独配置重排。结果会说明当次实际使用的方式。
- **想解决眼前的问题。** 在编辑器点「问这篇文档」可以就地核对；想换话题，可直接去「AI 问答」。指定本地资料后，证据不足时会提示缺口。独立问答支持选同一空间的最多五篇文档，并可另附最多五个文本附件。已授权 Brave Search 的情况下，模型按问题决定是否查公开网页。[资料范围与附件限制](KNOWN-LIMITATIONS.md)
- **准备长期维护一个主题。** 用「知识 Wiki → 范围与维护」授权资料，整理后进入「待审阅」。两份文档记载不一致时，核对两端原句，再决定发布、退回或仅保留摘录。来源更新后，原有引用仍可用于查看历史摘录；跳往当前原文时需要重新核对。[Wiki 变更示例](DELIVERY-v0.9.4.md)

### 书房同伴如何成长

在左侧「书房同伴」任选墨团、砚舟或知微，点「显示桌宠」回到文档。小角色停在编辑器左侧或右侧，窄窗自动收成书签。文档问答开始时它会陪读，回答就绪时短暂抬头；专注或减少动态适合需要安静写作的时候。

保存文档后，可以从页边角色菜单预览「记录本次完成」，确认文字和类型再写入经历。同一文档一天最多记录一次，每天最多两条。成长页分别显示「初遇」「相识」「同行」的进度与下一步条件，可在「故事」续读或到「相册」重看 CG。同伴动作、经历与故事在本机运行，不产生独立的模型调用。[书房同伴操作说明](DELIVERY-v0.9.6.md)

## 本地存储与服务边界

文档空间是应用管理的一组副本，可以收集多个来源目录里的文档。常规导入保留原件，比较和采纳外部更新由用户发起。高级的「打开本地目录」会直接编辑所选目录里的文件。备份、恢复与升级前的资料保护见[本机安装、备份和回退](LOCAL-INSTALLATION.md)。

编辑、离线示例、关键词检索和同伴故事可以先于模型配置使用。生成真实回答、整理 Wiki、构建向量和调用重排时，相应的服务商会收到该任务所需的问题、正文片段或候选证据。启用网页搜索后会向 Brave 提交经过校验的公开查询。模型密钥存入 macOS 钥匙串。当前支持 Markdown、TXT、JSON、MMD 文本资料；图片或 PDF 的 OCR、多人协作与跨应用悬浮桌宠的进展见[路线图](ROADMAP.zh-CN.md)与[已知限制](KNOWN-LIMITATIONS.md)。[模型与隐私](../SECURITY.md)

GitHub 提供源码及校验和，本机可自行构建独立应用。首次试用请从[源码快速开始](QUICKSTART.md)进入；操作入口、日常使用步骤与故障处理见[用户手册](USER-MANUAL.zh-CN.md)。实现、验证与版本变化见 [4A 架构](ARCHITECTURE-4A.md)、[技术栈](TECH-STACK.md)和[变更日志](../CHANGELOG.md)。
