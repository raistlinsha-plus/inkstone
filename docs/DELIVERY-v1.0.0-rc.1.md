# Inkstone 1.0 首个发布候选

2026-11-21 · v1.0.0-rc.1 · Apple Silicon Mac，macOS 13+。本次交付用于试用和回归。公开发行状态以 [GitHub Releases](https://github.com/raistlinsha-plus/inkstone/releases) 为准。

## 可以试用什么

1. **在自己的资料中提问。** 导入[阅读活动计划和复盘](../examples/v0.7.3/README.md)，先问计划与实际场次，再追问参加者反馈。打开每项回答的引用，看数字与条件能否在所选文档中找到。复合问题可能只有部分证据。
2. **核对 Wiki 的一次改稿。** 在 Wiki 里授权两篇笔记，整理并审阅一次。改动原文中的数字，再整理、查看候选主题，可对照同一来源上版和本次的引文与行号。取消勾选一篇资料，点击「查看清除范围」查看影响数量。确认时应用会再次核对，期间有改动须重新预览。发布过的主题、版本及待审改动可能都依赖一篇原文。
3. **在编辑器和文档列表中连续操作。** 打开文档「…」，直接点击另一篇文档，或用 Esc 回到原按钮。输入法正在选字时，菜单保留输入法对该按键的处理。
4. **让终端里的工具引用笔记。** 在桌面「模型与设置」中建立一个空间授权。用 CLI 先 search，拿到引文标识后再 read，可取得当时版本的原句与行号。来源改稿或连接撤销后旧读取会返回错误。构建和首次配对见[外部工具接入手册](EXTERNAL-TOOLS.zh-CN.md)。

正文编辑器刚就绪时的一次异步刷新，可能把已经输入的首字替换成打开文档时的旧内容。候选版现在保留这次输入，并继续接受之后从外部传来的文档修订。

## 验证结果

冻结的中文 40 题中，有 34 道需要原文。关键词模式完整取证由 13/34 提高至 24/34，命中必需片段由 16/48 提高至 35/48，越界 0/40。仍有 10 道没有取齐。旧集 9/9 道有据题取齐，64 题开发集中的 52 道有据题取齐 49 道。各组独立计算。原文是否进入上下文、真实服务是否返回，以及最终答对多少，分别统计。[评测口径](../evals/v0.9.1/README.md)

真实关键词回归使用 gpt-4.1-mini。40 题跑完，共 27 次 HTTP 请求；部分题由本地直接处理。抽查发现，在 28 道原文可完整回答的题中，8 道返回缺证；另有回答漏引或把未检出说成资料没有记载。[逐项抽查与剩余漏证题](../evals/v1.0/RETRIEVAL.zh-CN.md)

单独封存的 52 题覆盖 12 个情景、25 份合成资料和 7 道追问。离线运行逐题核对所选资料和对话历史，未向模型发出请求。该题组需要另外采集回答，再由人工对照封存答案逐条评分。[公开题面与复现方法](../evals/v1.0/independent/README.zh-CN.md)

## 正式版放行条件

独立未见题组需要按冻结规则人工核对正确率、引文支持率和严重错误。首次使用需要 5 位目标用户实测。系统中文输入法、VoiceOver、性能对照和安装分发也有各自的验收记录。公证安装包另需 Developer ID 和干净 Mac 验收。详细目标见[1.0 产品与发布方案](design/v1.0.zh-CN.md)。
