# v0.7.0 功能收口候选交付

2026-11-07；构建标识 **0.7.0-rc.4**。本轮实现正式版设计中的文档导航、单篇彻底删除及体验收口，包含用户补充的左侧“新建”图标样式修复。正式标签继续等待原生交互、自然多日试用和素材签收，不将功能完成等同于发行完成。

## 已实现

- 文档默认按中文自然名称升序，2 排在 10 前；相同名称或修改时间用稳定 ID 收尾。打开文档不改变普通列表顺序，“最近”单独按访问记录排列。
- 名称升序/降序、修改时间排序、置顶折叠按空间保存；侧栏和完整资料页同步选择。列表有独立滚动区、稳定 key 和滚动锚点。
- 回收站标题仅打开只读详情，恢复是显式操作。单篇彻底删除先核对副本范围，再输入“删除”；默认聚焦取消。
- 后端记录 prepared/committed/completed/rolledBack 阶段：承诺删除前可回退，提交后失败保留待清理状态，重启恢复按日志推进；operationId 幂等，响应丢失先查询状态。
- 清理受管理副本、专属附件、历史、恢复草稿、索引、日历与失效引用；导入原件、已有问答/确认经历文本和用户备份保留。来源已不可用时历史预览明确提示，继续问答仍核对现存资料。
- “新建”和“导入文档”使用相同高度、图标和文字对齐规则；问答头部减少占高，新会话明确“首次发送后固定范围”；紧凑同伴仍可进入手札和确认完成。
- 暂不开放无实际效果的称呼设置，旧值保留并可删除。没有新增模型调用、生产第三方依赖或系统口令配置。

## 数据与安装

catalog 由 schema3 升至 schema4，新增删除时间、生命周期 revision、删除日志和短期预览令牌。旧回收站项无可靠删除时间，显示“升级前已移入”。索引仍 schema3，会话/同伴库仍 schema1，备份仍 format2；备份兼容旧 catalog，未完成删除期间拒绝导出半态。

本机最新整理时正常保存退出旧 v0.6.2 应用，重新备份当时的 336 篇文档，并验证完整产品备份。原始 schema3 快照在副本上制作产品 ZIP，不以备份操作提前迁移生产目录。现已统一为 `/Applications/Inkstone.app` 一个日常安装入口，版本 rc.4，临时签名和二进制指纹核对通过。

生产 catalog 已迁移至 schema4，22 个 SQLite 文件完整性检查通过。现有文档的身份、标题、路径、状态全部保留；6 篇受控项目文档来源更新，其余现有正文不变；新增本轮交付、评审、正式版设计及本机管理 4 篇，合计 340 篇。13 份来源或基线不可用的历史副本保留原样。

旧应用副本及旧生成缓存已撤销启动登记并清理，约 16.66 GiB；源码、历史和资料备份保留。见[本机部署、清理与后续更新约定](LOCAL-INSTALLATION.md)。安装、快照、清理、迁移和文档同步回执分别存放于私有 artifacts，不随公开源码发布。旧版程序不能读取升级后的 schema4，回退需恢复对应资料快照，不能只换回旧程序。

## 验证

完整默认检查通过：前端 **53 文件 / 282 项**，Rust **178 通过 / 6 项显式远程忽略**；类型、工具链、工具测试、Worker、生产前端构建、原型和文档检查通过。

新增定向回归覆盖自然排序/同名同秒、两个资料视图同步、偏好保存失败、删除确认单次提交、显式恢复、响应丢失查询、原件和邻近文档保留、草稿/历史/索引清理、过期预览、symlink、准备失败回退、提交后中断续清，以及备份/写入互斥。这里的故障注入覆盖阶段边界，不宣称所有磁盘设备故障均可恢复。

生产 React 前端以独立合成 IPC 验证 10 次打开不移位、排序重开、最近视图、回收站详情/删除、按钮对齐；另复核首问/追问/拒答、来源、停止、再生成和 1440/1280/960 六种布局。截图与断言分开，模型请求为零。隔离应用五次冷进程与 WebView bootstrap 通过，系统凭据在该构建中禁用。

真实 API、生产冷启动与最终复核见 [本轮评审](REVIEW-v0.7-rc4.md)。完整自动检查不代替实际 Mac 中文候选、VoiceOver 或钥匙串授权验收。

## 正式发布仍需完成

1. 至少五个不同自然使用日的成长体验与不打扰评估，不通过改系统日期模拟。
2. 9 阶段立绘、6 CG 的像素水墨终稿、小尺寸、阶段一致性和来源/许可签收；当前仍为静态候选插画。
3. 实际 Mac 中文输入、快捷键、系统文件选择、来源落文和 VoiceOver 集中验收。
4. 对外 macOS 安装包还需 Developer ID、公证与跨机检查；当前包仅完成本机临时签名验证。

本轮没有创建稳定 GitHub tag/release。后续进入 v0.7.0 时沿用本候选的已验证改动，仅关闭上述发布门槛及真实试用发现的问题。
