# Inkstone v0.7.6–v0.7.8 交付导航

本轮按证据选择、问答体验和书房同伴拆分为三个版本。日常从「应用程序 → Inkstone」打开，标题栏显示 v0.7.8。

| 文档 | 用途 |
| --- | --- |
| [v0.7.6 交付](DELIVERY-v0.7.6.md) | 本地问答的原文取证、回归及预留题口径 |
| [v0.7.7 交付](DELIVERY-v0.7.7.md) | 独立问答、首次使用和 Wiki 整理流程 |
| [v0.7.8 交付](DELIVERY-v0.7.8.md) | 墨团动效、静态模式和阶段奖励 |
| [v0.7.5 交付](DELIVERY-v0.7.5.md) | Brave 测试连接、问答联网状态与对照基线 |
| [v0.7.4 交付](DELIVERY-v0.7.4.md) | 草稿、权限、引用位置和 Wiki 清理 |
| [变更日志](../CHANGELOG.md) | 各版本改动记录 |
| [本机版本与启动管理](LOCAL-INSTALLATION.md) | 更新、备份与回退流程 |

想体验知识问答，可以复制导入两篇[虚构阅读活动笔记](../examples/v0.7.3/README.md)，在独立问答中添加资料并核对原文。想体验整理流程，可以在同一空间启用 Wiki、勾选要整理的资料并审阅待发布变更。墨团试点从书房同伴设置进入。

自动回归分别记录本地证据、合成浏览器流程、隔离应用启动和本机实际升级。真实 Brave 直连探测在收到 HTTP 响应前超时。实际账号的搜索及网页引用待网络可达时补验。墨团的五个自然使用日观察同样保留为单独的验收项。
