# Inkstone v0.7.0 正式版交互原型

本机预览 <http://127.0.0.1:28710/>，对应[完整设计稿](../../docs/design/v0.7-stable/README.md)。基于当前 rc.3 的纸白、墨绿与 Lucide 组件语言，重点评审稳定导航、单篇彻底删除、问答层级和同伴手札。

## 可操作路径

1. 在“文档”依次打开 02、100：名称顺序不变；切到“最近”，100 排在最前。
2. 通过列表右上排序入口切换名称升序、降序、修改时间；搜索过滤、置顶/取消置顶、新建合成文档可操作。
3. 回收站点击“旧版活动草案”只看摘要；可恢复，或选择彻底删除，输入“删除”确认。可模拟一次准备失败并重试；这里只移除内存合成项。
4. “问答”查看展开布局，打开来源，输入“那哪个方案满意度更高？”演示资料不足；保存合成答案、预览插入可操作。
5. 打开同伴手札，切换经历、新章、相册和设置；图像均标记为既有概念预览。
6. 960px 使用编辑/问答两栏任务布局；1280px 展开问答时切为两栏，避免挤出过窄正文；1440px 可三栏阅读。

## 边界

独立合成数据，无 Tauri IPC、生产文件访问、真实 API 或密钥输入；不使用浏览器持久存储，刷新重置。CSP 限同源资源，页面不含 CDN。除本地开发热更新外无网络功能。

正文只展示合成内容，模式切换用于布局评审；不重新实现 Milkdown、CodeMirror 或完整 Markdown 往返。格式按钮以说明提示表示沿用现有编辑器，插入只演示位置。问题只支持固定满意度追问，其他问题保留输入并提示；不是可自由问答的助手。生产后端事务、崩溃恢复、模型流、草稿持久化与成长门槛均以设计规范及后续测试为准。

顶部场景条与模拟故障控件属于评审工具，不进入正式产品。默认取消、键盘焦点环绕、Escape 关闭可演示；不声称已通过系统 VoiceOver 或完整可访问性验收。

## 资源与开发

`public/assets` 两张图逐字节复用既有 v0.7 概念，来源见[原概念资源说明](../v0.7/assets/manifest.json)；不在此追加新的分发许可，不将其当最终像素资源。UI 图标为 lucide-react（ISC），React（MIT）、Vite（MIT）；生产依赖未更改。完整依赖由本目录 package-lock 固定。

运行 `npm install` 后 `npm run dev -- --host 127.0.0.1 --port 28710 --strictPort`。本轮因系统 npm 缓存权限不可写，使用工作区被忽略的专用缓存完成安装，未修改系统缓存权限。预览由本轮启动并保持运行。

验收使用 Codex 内置浏览器，截图见[设计画面](../../docs/design/v0.7-stable/SCREENS.md)，回执见[validation.json](validation.json)，视觉核对见[design-qa.md](design-qa.md)。构建使用本目录依赖通过；未调用真实 API、未删除用户资料、未对外部署。
