## 五项视觉检查

| 项目 | 观察与结论 |
| --- | --- |
| 字体 | 系统 UI 与正文、中文 serif 标题延续原生；列表编号与文字同一基线，长段自然换行。原型采用正文 16/28、H1 32，属于新稿明确规格；无在线字体。 |
| 间距与布局 | 顶栏/工具条、12/16/24 间距规则可见；列表新增最近和排序，置顶独立。1320 设计 260/700/360 对原生 304/636/380 为明确调整，保留用户拖宽的生产要求。 |
| 色彩 | 纸白 #FFFEFA、绿 #3C6753 与选中 #E6ECDD 复用；危险操作使用文字和红色，错误说明就近，不只改变边框颜色。截图检查不等于完整对比度合规。 |
| 图像 | 复用已有墨团/书房概念文件，object-fit:contain 无拉伸，界面标预览；没有 CSS/SVG 冒充角色。Lucide 为既有图标来源。最终像素资源尚未签收。 |

## 交互与布局复核

- 默认排序连续打开十次不变，最近独立更新，名称降序/修改排序/搜索可用。
- 回收站标题只打开摘要；显式恢复、空态、输入确认、准备失败、重试删除合成项走通。
- 候选来源、满意度缺项追问、同伴经历/新章/相册、Escape 返回走通。
- 删除弹窗初始焦点是取消，Tab/Shift+Tab 环绕，960 高度下底部操作可达。
- 1440×900 三栏、1280×800 三栏与展开任务布局、960×640 两栏均有截图；页面整体无横向溢出。长正文/时间线在自己的容器滚动。
- 本轮内置浏览器读取的页面 error/warn 日志为空。没有真实模型调用和生产资料写入。

## 后续验收

本原型未实现生产编辑器、跨库删除、崩溃恢复或真实 SSE；不承担这些行为测试。完整 VoiceOver、中文组合输入、200% 文本、真实模型、自然多日成长与终稿许可继续作为生产发布门槛。见 [开发验收计划](../../docs/design/v0.7-stable/PLAN.md)。

实施清单：先共享选择器和稳定 key，再生命周期迁移与故障测试，随后把本稿密度调整落入既有组件，最后集中原生与模型验收。P0/P1/P2 的原型问题已闭环；系统读屏和素材签收没有被以 P3 降级跳过，而是独立生产门槛。
