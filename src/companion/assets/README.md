# v0.7 candidate artwork

Nine distinct character-stage portraits and six story scenes are local release-candidate static illustrations. The original project characters and references were generated with OpenAI imagegen; no franchise assets or external character references are included. SHA-256, dimensions and review status are in manifest.json.

These are not finished animation sprite sheets. Pixel-grid cleanup, reduced-size redraws, motion frames and final release artwork/provenance sign-off remain separate gates. Prototype base portraits and the Motuan afternoon scene are reused as the matching initial-stage/corresponding scene candidates; the other eleven files were generated for the production candidate.

## v0.7.8 Motuan pilot

The [Motuan sprite](../MotuanSprite.tsx) and the [acquaintance bonus scene](motuan-pilot-cg.svg) are original vector artwork authored in this repository under its Apache-2.0 license. They use pixel geometry and layered ink washes without outside images. The sprite uses short local CSS animations. The existing `manifest.json` describes the original raster portraits and story CGs.
